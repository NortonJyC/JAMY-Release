# JAMY 3.1.13 使用范围与限制

本页对应本次免费测试发布的 Windows **3.1.13 · 2026-10-30 构建**。后续源码中的改动不自动等于此安装包已包含。大小单位采用二进制：1 KiB = 1,024 字节，1 MiB = 1,048,576 字节。

## 资源库容量：推荐做法与技术边界

- **推荐做法**：按项目、用途或年度分库；从有代表性的小批素材开始，确认导入、搜索、预览、备份和重开表现后再扩充。
- **推荐数量尚无统一结论**：没有标准硬件、素材组成和实机性能基准支撑一个对所有用户都适用的“单库推荐 X 万项”。不能用数据库能写入的数量，代替日常操作体验。
- **当前数量保护**：部分查询与索引、建库扫描、旧库迁移按最多 **200,000 项资产 / 50,000 个目录** 检查。到达这些边界前应考虑分库；这些值不是推荐存放量，也不代表所有入口、操作或机器均可承载同样规模。
- **旧库迁移还有体积限制**：旧版 `jamy_db.json` 输入最高 **128 MiB**；目录、标签与元数据较多时，可能在达到资产数量边界前先触及其它预算。
- 资源库体积还包含缩略图、缓存与备份。磁盘剩余空间不足时，导入、预览或维护可能被拒绝。

## 3D 交互预览

### 自动预览、手动确认与体积上限

| 格式 | 允许自动预览的大小 | 超过自动阈值后 | 交互预览体积上限 |
| --- | --- | --- | --- |
| FBX / OBJ / DAE | ≤ 8 MiB | 手动确认加载 | 64 MiB |
| STL / PLY | ≤ 16 MiB | 手动确认加载 | 128 MiB |
| GLB / GLTF | ≤ 32 MiB | 手动确认加载 | 256 MiB |
| BVH | ≤ 2 MiB | 手动确认加载 | 8 MiB |

超过体积上限时不进行交互预览；可在外部软件中处理或制作较轻的预览副本。大小未知或异常的文件不会直接自动加载。

自动缩略图与交互预览采用不同预算。例如 `.gltf` 自动缩略图的模型和依赖快照合计最高 **32 MiB**；不能用“可交互预览 256 MiB”推断所有自动缩略图也支持同样大小。

### GLTF 依赖与压缩

- `.gltf` 清单最高 **16 MiB**；模型与已计入依赖合计最高 **256 MiB**。
- 最多 **64 个 buffer**、**256 张 image**，依赖条目合计最多 **320**。
- 模型的本地依赖需通过路径与授权检查；缺失贴图或缓冲区、远程/不安全依赖、部分扩展与压缩方式可能导致缺材质或拒绝预览。请尽量保留完整的本地模型文件结构。
- 格式可识别不等于每个扩展和第三方导出器都完全兼容。部分 `.gltf` 动画失败只有在界面明确提供时，才能选择静态查看。

### 骨骼与动画复杂度

纯骨骼可视化的主要保护边界为：**512 根骨骼、4,096 个节点、128 层深度、32 个动画片段、1,024 条轨道**；单片段最长 **3,600 秒**。准备后用于播放的动画最多 **100,000 个关键帧 / 2 MiB 采样数据**。3.1.13 可先在原始 **500,000 个关键帧 / 10 MiB** 的范围内移除严格恒定的冗余内采样，准备仍有时间预算；超出时不会靠“简化骨骼”取消限制。这组边界不应解释为所有带蒙皮模型的统一规格承诺。

BVH 还要求最多 **10,000 帧**，并且 **骨骼数 × 帧数 ≤ 50,000**。因此骨骼数与帧数不能同时取各自最大值。异常坐标、旋转或时间也可能被拒绝。

没有对外承诺适用于所有模型的统一面数上限或显存最低要求。源文件大小只是解码后场景内存的间接指标；“低负载绘制”减少绘制开销，但不会解除解析准入限制。

## 图像、贴图与大图查看

### 普通缩略图与受控解码

- 原文件最高 **512 MiB**，单页最高 **40,000,000 像素**，元数据中的页数最多 **32 页**。
- 多页缩略图处理不等于多页编辑或完整动图还原。独立大图查看采用单页/单帧规则。
- **8,192 × 8,192 = 67,108,864 像素**，超过普通 4,000 万像素边界。HDR / EXR / PSD / TIFF 等不能因为扩展名受支持，就保证任意 8K 或 16K 文件可预览。
- 对需要常规预览的高分辨率专业素材，可另备 4K 等较轻的预览副本；原文件保留用于专业制作。小于像素阈值也仍受文件大小、编码和解码内存限制。

### 大幅 PNG / JPEG 的专用路径

满足受控检查的 PNG / JPEG 可以使用大图专用路径：原文件最高 **256 MiB**，每边最高 **16,384 像素**，总像素最高 **268,435,456**。

- PNG 要求非交错、单帧，8/16 位灰度或 RGB 及其透明通道等受支持结构；动画 PNG、部分附加块或异常结构不适用。
- JPEG 要求基线/非渐进的受支持结构，并通过位深、通道、方向等检查。
- 其它格式没有因此自动放宽到相同大小。

### 独立图片查看器

受控查看器原文件最高 **256 MiB**、每边最高 **16,384 像素**，普通图片仍受 **4,000 万像素**限制；只有符合前述检查的大 PNG / JPEG 使用更高像素上限。位深、通道、单页、临时磁盘空间与内存预算会进一步影响可用性。

PSD 仅预览 **8/16 位 RGB 或灰度合成图**，不提供图层编辑；CMYK、其它颜色模式、无有效合成图或不兼容压缩可能失败。HDR/EXR 预览不是专业色彩、通道或曝光合成工具。RAW / DNG / IFF / PICT 虽可登记收录，但不承诺通用相机 RAW 或全部历史编码都能解码。

## 音频与视频

- 整段音频波形：原文件最高 **64 MiB**、时长最高 **3,600 秒**、最多 **8 声道**，全部声道的解码采样数合计最多 **134,217,728**。高采样率或多声道文件可能在达到时长上限前先触及采样预算。
- 波形生成有独立的解码和内存保护；波形不可用不会主动禁止普通播放器播放。
- 视频和音频的扩展名只表示容器/文件类别。实际能否播放取决于内部编码与当前运行时，不保证任意 MOV、AVI、MKV 或其它容器中的所有编码均可播放。
- 视频没有在此公布一个适用于全部编码的统一大小/分辨率保证；解码能力、源文件、内存和硬件仍是实际边界。

## 导入、扫描与批量整理

- **普通主窗口多文件复制**：普通批次最多 **200 项**；较大本机文件批次按 **201–20,000 项**分段处理，支持相应的暂停、继续和恢复流程。
- **目录 COPY**：单次最多 **128 个根、50,000 个文件、5,000 个目录、55,000 个文件＋目录节点**；扫描原始条目最多 **200,000**、深度最多 **128 层**。
- **目录 LINK**：单次最多 **128 个根、50,000 个文件、5,000 个目录、55,000 个文件＋目录条目**；原始扫描条目最多 **100,000**。这不是普通文件批次或 Quick 的通用上限。
- **已有目录建库扫描**：扫描保护最高 **200,000 项文件、50,000 个目录**，还受目录深度与原始条目数量约束。
- **批量修改显示名**：每次 **1–200 项**，只修改库内显示名，不修改磁盘文件名。可撤销资格只针对当前库、当前会话中最近一次符合条件的操作。
- **手机传输**：传输协议单文件最高 **16 GiB**，仍受可用磁盘、连接与实际入口检查约束。需要显式允许并手动开启局域网服务。
- 大任务的清单、日志与中间状态还有独立预算；不能只根据文件数量或文件总字节数推断一定能收录。Quick、网页收录、目录拖拽与目录选择器也不是完全相同的流程。

## 文本、代码与数据安全

- 文本/代码预览最多读取开头 **256 KiB**；支持的文本编码包含 UTF-8、带 BOM 的 UTF-16，以及符合解码检查的 GB18030。二进制内容或异常编码可能被拒绝。预览不执行代码。
- 仅建立索引依赖原目录与存储盘，原文件移动后不会保证自动追踪到新位置；根据界面提供的重新定位入口处理。
- 软件中的分类目录不等于同名磁盘目录。目录同步只对相应入口与设置管理的范围生效，不能视为任意外部目录都会自动发现新增文件。
- 数据库快照保存分类、标签、项目、材质与预览设置等记录，**不包含素材原件或库外贴图备份**。复制当前库目录也不代表复制了库外索引引用。
- 手动记录备份独立保留，最多 **100 份**；达到上限停止新建，不自动删除旧手动备份。自动备份保留最近 **5 份**，恢复前备份保留最近 **2 份**，恢复处理中另需保留的备份不按普通轮换处理。同盘快照不能防止磁盘损坏。
- 不同数据结构版本之间不能假定可以直接降级打开。升级旧库前请独立保留素材原件与升级前记录备份。

## AI 图片分析与搜索（Beta）

- 当前图片分析限静态 **PNG / JPEG / WebP**，不是对视频、音频、模型、文档或所有图像格式的通用识别。过大或不兼容的图片需要较轻的静态副本。
- **本地 AI** 与 **自定义 API** 可用；官方 JAMY 云端服务尚未开放。本地组件首次准备约需数 GB 下载与磁盘空间，以界面实际缺少项为准；准备完成不等于图片分析与搜索两项能力均已检查通过。
- 本地分析逐张执行，并受可用内存检查影响。自定义 API 同时分析数默认 **2**，可设 **1–4**；更高并发不保证单张更快，服务限流时会等待或降速。
- AI 搜索单库处理范围最多 **200,000 项**，查询输入最多 **512 字符**。这是语义搜索处理范围，不是资产收录上限；超限或准备失败时仍可使用普通关键词搜索。
- 图片描述生成与搜索数据准备分别配置；已有 AI 描述并不自动保证搜索准备完成。人工纠正、模型变化和图片来源变化会影响后续结果与任务。
- 自定义 API 分析会向已授权服务发送处理后的图片等内容；搜索准备发送描述、标签等索引文本，查询发送搜索词。服务商可能收费，连接检查也可能产生请求费用。每日请求数上限按 **UTC 日期**计算，不是金额上限。
- 只有应用后的 API 授权与设置生效；撤回授权或移除本机密钥不能撤回已经发送的数据和已发生的费用。结果未知时应先核对服务记录，避免反复发起请求。
- AI 可能遗漏颜色、数量或细节，相关度排序也不等于精确命中。请核对原图，不把生成标签、描述或搜索结果作为事实保证。
