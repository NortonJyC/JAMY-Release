# JAMY 使用手册

适用版本：Windows 3.1.13 · 中文界面

文档版本：完整文字初稿 v1 · 2026年10月29日

JAMY 用来收集、整理、预览和查找创作素材。本手册从第一次导入三张图片开始，逐步讲解模型与动作预览、AI 图片分析、快捷收集、项目组织，以及素材库的备份维护。

本册针对当前 Windows 版本。Mac 版的安装、权限和快捷键需要单独说明，不直接套用本册的 Windows 操作。

## 怎样阅读这本手册

**第一次使用**：从第01章开始，完成“导入—查看—标记—找回—取用”，再读第02章，分清资源库、分类、项目和原文件。

**已有一批素材**：重点看第03—08章，先确定 Copy 或 Link，再决定分类、标签和项目的组织方式。

**需要看模型、动作或使用 AI**：跳到第09—14章。配置和能力边界分别写在对应章节中。

**经常收集素材或准备管理大库**：看第15—19章，了解 Quick、手机传图、目录同步和备份。

**想把功能组合起来**：看第20—27章的八种进阶玩法。其中玩法3是“为一个 AI 短片建立素材工作台”。

本册按钮名称以中文界面为准。图标按钮可以先悬停查看说明；窗口较小时，部分内容需要滚动才能看到。操作后的“完成判断”用于确认结果，不能用“点过按钮”代替“已经成功”。

### 先记住四个习惯

1. 新功能先用少量普通素材练习，确认结果后再扩大范围。
2. 导入后看成功、重复、失败等实际结果，而不是只看选择了多少文件。
3. 移动、删除和恢复之前，先分清是在改变整理记录，还是在改变磁盘文件。
4. 素材文件与整理记录都要保护；资源库记录备份不能代替原文件备份。

## 第01章 第一次使用 JAMY

**本章目标**：建立资源库，导入三张图片，给其中一张添加标签与评分，再通过搜索找到它并取用。

### 1.1 开始前准备

准备已经安装的 JAMY、三张内容不同的 JPG 或 PNG 图片，以及一个可以长期存放资源库的位置。建议人物、建筑、风景各选一张，不必一开始就导入整个素材硬盘。

本章使用普通搜索，不需要配置 AI 或填写 API。已经进入主界面的用户，可以从1.4节开始。

### 1.2 阅读使用许可与隐私政策

首次启动时，JAMY 会显示“使用许可与隐私”。分别查看“使用许可”和“隐私政策”；如果接受其中内容，勾选确认框，再点击“接受并继续”。如果不接受，可以选择“不同意并退出”。

后续可选功能的说明还应在使用该功能时阅读。接受基础使用许可不代表已经配置好 AI 或启动手机传图。

### 1.3 选择资源库位置

资源库用于保存 JAMY 管理的素材与整理记录，和软件安装目录不是同一概念。例如软件安装在 C 盘，资源库放在 D 盘。

1. 在 Windows 文件资源管理器中，新建一个空文件夹，例如 `D:\JAMY素材库`；没有 D 盘时选择其他合适的位置。
2. 回到 JAMY，点击“选择位置并创建资源库”。
3. 在系统窗口中选中准备好的文件夹并确认。
4. 等待初始化完成，进入主界面。

**完成判断**：能够进入资产库界面。新库没有自己的素材是正常现象。

已有 JAMY 资源库应使用“选择已有资源库”。如果旧库暂时打不开，先核对路径、磁盘连接和提示，不要对原目录反复执行创建。

首次练习建议使用电脑内置硬盘上的固定位置。以后迁移时按第18章操作，先不要直接在 Windows 中改名或挪走资源库目录。

### 1.4 认识四个主要区域

- 左侧导航：切换资产库、项目和素材分类。
- 中间素材区：显示当前范围内的素材。
- 顶部搜索与筛选区：查找和缩小素材范围。
- 右侧详情区：选中素材后查看信息、标签、评分和预览。

第一次先使用“资产库”。“项目”用于组织某个具体创作任务需要的素材，后面再练习。

### 1.5 新建练习分类

1. 点击左侧“资产库”。
2. 找到左侧“文件夹”标题，点击右侧的＋。
3. 输入“第一次使用”，按 Enter 确认。
4. 等待名称出现在侧栏。

如果已经有“我的收藏”“工作项目”等分类，可以保留。它们的名称不代表里面已经有素材。

创建分类后不必依赖界面是否自动切入；下一步会明确选择导入目标。

### 1.6 导入三张图片

1. 默认网格布局下，点击素材区域右下角的圆形＋，悬停说明为“导入资源”。列表布局的入口位于顶部工具区。
2. 在“导入至文件夹”中选择“第一次使用”。本次标签和星级先留空。
3. 点击“图片”。在系统文件窗口中按住 Ctrl 逐张选中三张图片，再点击“打开”或相应确认按钮。
4. 在“选择导入模式”窗口中点击“复制文件 (Copy)”。本次可以不勾选“记住我的选择”。
5. 等待导入结果，不要在处理中切换资源库。

**点击 Copy 卡片就会开始导入，没有第二次“确认导入”。**

Copy 会在资源库中保存副本，原位置的图片仍然保留，并额外占用存储空间。Link 则引用原位置文件，移动、改名或删除原文件会影响后续访问。第一次练习用 Copy。

**完成判断**：三张都成功时会看到“已导入3个资产”一类的成功提示，目标分类中出现三个素材；缩略图可能稍后才生成。有重复或失败时，以实际结果为准，先查看原因再重试。

### 1.7 查看大图

1. 单击一张图片，右侧显示详情，底部显示选中数量。
2. 双击同一张图片，进入大图界面。
3. 查看后点击左上角“返回”。

也可以先选中图片，再点击底部“查看所选图片”。普通大图界面可用 Esc 返回；如果已全屏，第一次 Esc 会先退出全屏。

### 1.8 添加标签和四星评分

1. 单击选中一张图片，在右侧向下找到“整理信息”。
2. 在“自定义标签”中点击“＋ 创建”。
3. 输入“练习素材”，点击“添加”或按 Enter 提交；无需自己输入井号。
4. 找到“评分”，点击从左数第四颗星。

**完成判断**：看到“练习素材”标签与 `4 / 5` 评分。再次点击同一评分会清除评分，不必为了保存而重复点击。

文件夹适合归类，标签适合补充内容、用途、状态，评分适合表达偏好。例如“场景参考”分类中的图片，可以带有“夜景”“霓虹”“待选”等标签。

### 1.9 通过搜索找回图片

1. 点击左侧“全部资产”。
2. 在顶部搜索框输入“练习素材”，完成中文选字。
3. 等待结果自动更新，无需按 Enter，也无需点击“AI 搜索”。
4. 找到刚才的图片后，点击搜索框右侧×清空搜索。

搜不到时，依次检查标签是否提交、输入是否正确、是否在“全部资产”、是否还留有类型或评分筛选条件。

### 1.10 定位并取用文件

1. 单击选中图片。
2. 在右侧详情中点击“在文件资源管理器中定位”。
3. Windows 会打开文件所在位置并定位它。
4. 需要放进项目时，复制这份文件，再粘贴到项目目录。

本章使用 Copy，定位的是资源库保存的副本。取用时先使用复制，不要直接剪切或移走库内文件。图片还可以通过详情中的“打开”入口交给系统默认程序。

### 1.11 完成检查与常见问题

确认你能找到练习分类、看到图片、打开并返回大图、添加标签和评分、通过标签搜索找到图片，并定位文件。

**刚进入软件没有图片**：新库不会自动包含电脑里所有文件，需要导入。使用已有库时先确认选择的是正确的库。

**导入了却看不到**：先看导入结果，再看“全部资产”，检查目标分类、搜索和筛选条件。

**缩略图暂时没显示**：先等待生成并检查任务提示。选中素材查看详情、定位文件，可以区分缩略图问题与文件访问问题。不要直接删库。

**退出前要不要总保存**：本章标签和评分在提交成功后保存，没有额外的总保存步骤；正在导入时先等任务结束。

**能不能删原图**：先确认是 Copy 还是 Link，并确认其他项目是否还依赖原图。练习时保留原图即可，不需要靠删除来验证。

## 第02章 资源库与素材管理的基本概念

**本章目标**：分清几种组织方式，避免为了分类反复复制素材，或误把整理记录当成原文件。

### 2.1 资源库 管理记录与素材文件

资源库是当前工作的整体范围，包含素材的管理记录，以及按导入方式保存在库中的文件。管理记录包括名称、分类、标签、评分、项目关联等信息。

一个素材卡片能显示出来，不等于对应的原文件一定在线。例如 Link 引用的移动硬盘断开后，记录可能仍在，但文件暂时无法读取。

因此遇到“找不到文件”，先查看提示和实际存储位置；遇到“找不到素材”，先检查当前库、分类和筛选。这是两类问题。

### 2.2 Copy 与 Link 怎样选择

**Copy 适合集中保存。** 例如零散参考图、下载的小素材、需要长期保留的文件。导入后有库内副本，代价是额外占用空间。

**Link 适合引用稳定的大型素材目录。** 例如已有结构清晰的模型硬盘。它减少重复复制，但需要保持文件位置、磁盘连接和访问权限。

选择时可以依次考虑：

1. 原文件是否会经常被移动、清理或覆盖？经常变化的临时目录不适合长期 Link。
2. 是否希望由资源库集中保管一份？希望集中保管时优先考虑 Copy。
3. 文件体积和剩余空间是否允许复制？不足时先规划存储，不要导入到一半再移动库。
4. 是否存在贴图、外部数据等依赖？先用少量代表性素材检查导入和预览，不能只检查主文件名称。

同一个资源库可以包含两种来源。取用、迁移和清理前，应按该素材的实际来源判断。

### 2.3 文件夹 标签 评分 项目分别做什么

**文件夹回答“放在哪一类”。** 例如人物参考、环境参考、模型、声音。适合稳定的大类，不必为每一个形容词建一层目录。

**标签回答“有什么特点、准备怎么用”。** 例如雨天、背光、待选、已确认、第一幕。一个素材可以有多个标签。

**评分回答“有多值得优先看”。** 它是你的判断，不代表系统检测出的画质。

**项目回答“这次任务需要哪些素材”。** 同一资源可服务于不同任务，不必为了每个项目先复制一套库内素材。加入或移出项目改变的是关联关系。

第一次整理可只选两层分类，搭配少量稳定标签。等实际需要出现后再细分。

### 2.4 搜索 筛选和 AI 搜索的区别

普通搜索使用已有名称、标签等信息，输入后更新结果；筛选用类型、评分、时间、颜色等条件缩小范围。

AI 搜索需要另行配置和准备可搜索内容，适合用自然语言描述需求。它可能漏掉合适的素材，也可能返回看起来相关但不满足细节的素材，因此仍需预览确认。

不要把“能导入某种格式”理解为“AI 已能看懂这种格式”。当前 AI 图片分析支持的范围见第13章。

本版没有可操作的智能文件夹创建与管理入口。你可以组合筛选条件，但不能按本册操作把它保存成自动更新的智能文件夹。

### 2.5 预览与编辑的边界

JAMY 适合查看、比较、组织和取用素材。模型预览中的光照、材质展示、姿态记录和封面，主要服务于在库内判断与浏览。

需要修改模型拓扑、制作动画、剪辑视频、生成 AI 画面或最终排版时，在相应创作工具中完成，再把输出收录回 JAMY。

特别注意：3D 预览可用不代表所有 DCC 工程都能直接打开；保存姿态不等于导出新的动作文件；调整预览材质也不等于重写原模型材质。

### 2.6 给自己定一个小型整理规则

用本章内容完成以下练习：

1. 写下三个最常用的大类，例如角色、场景、声音。
2. 选定三个状态标签，例如待选、重点、已用。
3. 约定四星表示优先候选、五星表示已确认。
4. 只整理十个素材，检查这些规则是否真的能帮助查找。
5. 不够用时再调整，不必一次建立几十个空目录。

**完成判断**：你能解释每个素材为什么放在这个分类、标签表达什么、评分代表什么。规则能帮助下一次取用，比规则数量多更有价值。

## 第03章 导入本地与网页素材

本章介绍怎样把电脑里的文件、整份目录和网页图片收录到 JAMY。操作前先确认左上方显示的是你准备使用的资源库。建议沿用“第一次使用”练习文件夹，先收录几份内容不同的小文件，熟悉结果提示后再处理大目录。

### 3.1 先决定使用 Copy 还是 Link

**复制文件（Copy）** 会在资源库内保存副本，原文件仍留在原处。它适合把零散素材集中收好，但需要额外磁盘空间。之后修改外部原件，不会自动修改已经复制入库的文件。

**仅建立索引（Link）** 保留文件原位置，在 JAMY 中建立记录。它适合已有稳定目录的素材盘。原文件和磁盘仍须可访问，Link 不是素材备份。已关联的索引目录可以使用目录同步，但单个文件没有“搬到哪里都能自动找回”的保证。

两种方式都需要保存记录、缩略图等数据，Link 也会占用磁盘。练习时建议使用 Copy，并保留外部原件。

### 3.2 从电脑选择几份文件

1. 在“资产库”页面点“导入资源”。网格等布局的入口是资产区域右下角圆形 **＋**；列表布局的 **＋** 在顶部工具区，悬停可查看名称。
2. 在弹窗顶部“导入至文件夹”中选择目标，例如“第一次使用”。“当前视图文件夹”跟随当前所在位置；“全部资产 (不分类)”表示暂不归入普通分类。练习时直接选文件夹名称更明确。
3. 点“图片”“3D 模型”“视频”“音频”中的合适类别，或使用其他文件入口。在系统文件窗口选择文件，多选可按住 Ctrl，再点系统窗口的确认按钮。
4. 系统文件窗口关闭后，在“选择导入模式”中点“复制文件 (Copy)”或“仅建立索引 (Link)”。**点击模式卡片就是确认**，普通文件不会再出现“开始导入”按钮。
5. 等待收录结果。成功提示会给出实际导入数量；新文件正常保存后，主界面会显示目标分类。缩略图可能仍需一段时间生成。

第一次练习不要勾选“记住我的选择”。以后使用拖放时，是否再次询问模式会受设置影响；不能仅凭没看到模式窗口就判断导入失败。需要调整时，到“设置 → 导入与快捷窗口”检查“导入前询问复制或索引模式”。

**完成判断**：在目标文件夹看到所选文件，点击其中一项能打开详情。以实际成功数量为准，不能把选了多少文件直接当成已收录多少文件。

### 3.3 收录一整个目录

目录导入会扫描电脑中的目录并建立相应分类结构，不会把压缩包当成目录展开。

1. 打开“导入资源”，先在“导入至文件夹”中选好父级分类。
2. 保持“本次导入规则”为空。如果已经设置标签或星级，先点规则区“清空”，再点“导入文件夹”。
3. 在系统窗口选择要收录的目录，确认后选择 Copy 或 Link。
4. 使用 Copy 时，等待扫描，然后在“目录复制确认”中检查文件数、目录数和空间规模，点“确认复制目录”。使用 Link 时，选择模式后会扫描并进行索引收录，不要等待一个并不存在的 Copy 确认页。
5. 在进度和任务中心查看处理状态。结束后检查目标分类和“本次目录收录结果”；有失败项时打开“查看完整失败报告”。

单次目录任务有范围限制，导入弹窗中的“文件夹导入范围与等待说明”会列出当前限制。目录很大、层级很深或磁盘较慢时，扫描也需要时间。超出范围应拆成较小目录；出现待核验任务时先处理原任务，不要马上把同一目录再导入一次。

新的 Link 目录导入通常会自动建立目录同步。若提示“文件已入库，但目录自动同步尚未建立”，文件收录与同步登记是两件事；请检查目录同步状态，无需为此重复导入。

### 3.4 从网页拖入图片

网页收录的入口是**从浏览器把图片拖到 JAMY**，并不是粘贴任意网页地址后保存整页。不同网站提供的拖放数据不同；需要登录的图片、受保护图片或特殊网页元素可能无法直接读取。

1. 在 JAMY 左侧展开目标分类；为避免目标不明确，准备把图片直接放到该分类名称上。
2. 在浏览器找到你有权保存和使用的图片，按住图片拖到 JAMY 的目标分类上，再松开。先用一张图片练习。
3. 如果出现“导入网页图片”说明，阅读来源、使用权限和网络访问提示。愿意继续时点“已了解，继续导入”；取消则停止本次收录。
4. 等待图片数据读取。如果出现导入模式窗口，使用“复制文件 (Copy)”；网页图片不能以没有本机路径的 Link 方式收录。模式窗口是否出现会受导入设置影响。
5. 查看实际结果，再打开目标分类确认图片。若提示“未能读取网页图片”，可先用浏览器把图片保存到电脑，再按本章的本地文件步骤导入。

首次说明被确认后，本机当前配置会记住这一版说明，后续不一定重复弹出。网页图片导入不会取得版权，也不会替你保存完整网页或许可证明；需要保留出处时，请另行记录。若库中已开启自动 AI 分析，符合条件的图片还会按当前 AI 设置继续处理。

### 3.5 看懂重复、失败和大批次结果

发现相同内容时，JAMY 可能跳过重复文件并显示已有资产。一般选择“不重复导入”即可；只有确实需要额外一份时才选择“仍保留一份”或“仍保留重复项”。同名不等于相同内容，改文件名也不一定能避开内容去重。

普通 Copy 批次结束后，可通过提示条“查看本次收录结果”检查逐项状态。确定失败的项目可使用“重新选择文件并重试”，重新核对来源和目标后确认。此结果入口保留当前库会话中的最近普通批次；不要把它当成永久导入历史。

主窗口 Copy 收录 201–20,000 个本机文件时，可请求“完成当前批次后暂停”。等当前部分确认后，再从“大批次收录任务”显式继续或取消剩余项。暂停不撤销已经收录的文件；“待核验”也不等于安全暂停。整目录任务与普通多文件任务的范围不同，请按各自窗口说明操作。

**本章练习**：把三张不同图片 Copy 到练习分类，再尝试收录其中一张。看到重复提示后选择“不重复导入”，确认库内没有无意增加一份。若缩略图暂时空白，先等待处理，不要通过反复导入解决。

<a id="chapter-04"></a>
## 第04章 文件夹与收件箱

文件夹用来归类，收件箱用来暂存待整理素材，“未分类”用来找到尚未归入分类的记录。“全部资产”则汇总当前库的素材，不是另存了一份文件。先理解这几个入口，后续整理就不容易把素材“找丢”。

### 4.1 新建、改名和建立层级

1. 在“资产库”页展开左侧栏，找到“文件夹”标题，点右边 **＋**。
2. 在“文件夹名称”输入框填写名称，例如“项目练习”，按 Enter，等待名称出现在侧栏。
3. 需要子分类时，右键点父文件夹，选择“新建子文件夹”。把新建项的默认名称改成“图片参考”，按 Enter。
4. 需要改名时，右键点对应文件夹，选择“重命名”，输入新名称并按 Enter。
5. 点父级旁的展开箭头，确认子文件夹在正确层级；再点分类名称查看内容。

文件夹改名改变的是 JAMY 中的分类名称。不要仅凭它与磁盘目录同名，就认定两者永远同步。旧库可能已有“我的收藏”“工作项目”等分类，可以继续使用，也可以另建练习分类；“我的收藏”在这里是文件夹名称，不是独立收藏开关。

### 4.2 把已有素材移入分类

1. 从“全部资产”、收件箱或原分类找到要整理的素材。
2. 单击选择一项；需要多项时按住 Ctrl 逐项点击。先看底部“已选中”的数量，确认没有多选。
3. 在所选素材上点右键，选择“移入文件夹…”。
4. 在目标菜单输入名称搜索，核对完整分类路径，再点目标文件夹。这里点目标就会执行移动。
5. 打开目标分类，确认素材已经出现。如果想取消归类，在同一菜单选择“未分类”。

这项操作调整资产的分类归属，不是把文件复制成多份。需要同一素材参与多个工作场景时，用项目归属更合适。移入其他分类后，原分类里看不到它是正常结果；可以回“全部资产”搜索确认。

批量移动后若出现“撤销本次批量移动”，可按提示预览并确认恢复。该入口有当前操作和会话条件，不要把它当成长期历史撤销。

### 4.3 每天整理一次收件箱

1. 点击侧栏“收件箱”，查看通过 Quick 等入口收录到这里的素材。
2. 先选一小组内容相近的素材，打开详情核对名称与内容；不确定的先留在收件箱。
3. 用“移入文件夹…”把选中项放入明确的分类。
4. 回到收件箱，确认这些项已移出；再检查“未分类”，处理其他没有分类的素材。

收件箱不是回收站。整理时把素材移入正式分类即可，不必删除。主窗口导入目标不提供收件箱选项；使用 Quick 时可明确选择收件箱。

### 4.4 整理文件夹位置与封面

1. 要调整层级，在侧栏按住文件夹名称拖动到目标位置。放在另一文件夹中部表示移入；上下边缘出现插入线时表示放到目标的前后位置。
2. 松开后展开相关父级，检查实际层级。如果要把子文件夹移回最外层，可右键选择“移至根目录”。
3. 要选封面，进入相应分类，选中一份已有可用缩略图的素材，右键选择“设为文件夹封面”。只有符合条件的素材才显示该入口。
4. 返回上层查看封面。想恢复时，右键点文件夹，选择“恢复默认封面”。

有缩略图的模型、音视频或文档也可能用于封面，不局限于图片。文件夹为空、素材缺失或缩略图未生成时，先处理这些状态，不要把按钮缺失解释成封面已经保存。

### 4.5 分类与目录同步的关系

普通分类管理和磁盘目录同步应分开理解。通过 Link 导入并成功关联的目录，可以跟踪目录内新增、修改、改名和移动；Copy 的外部原件仍独立于库内副本。

1. 打开“设置 → 存储与资源库”，找到“目录同步”。
2. 查看列出的“索引目录”或“库内副本”，先确认同步的是哪一处路径。
3. 按需启用“自动同步目录变化”。旧版已收录的外部目录需要关联时，使用“关联已有外部索引目录”，选择正确目录。
4. 需要立即核对时点“立即同步”，等待结果；部分目录不可用时检查磁盘和目录，不要马上删除资产记录。

目录离线时会暂停该目录同步；已确认删除的文件会保留失效记录供后续处理。自动同步不能替代备份，也不能保证在已关联范围之外任意搬动文件都能继续匹配。

**常见问题**：“移入分类后，磁盘文件怎么没跟着移动？”——这里完成的是分类整理；查看真实文件位置，请使用“在文件资源管理器中定位”。“收件箱空了，全部资产还有文件？”——这表示素材已归类或仍在库中，属于正常现象。

**本章练习**：建“项目练习／图片参考”两级分类，把两张练习图片移进去，再将其中一张移到“未分类”。完成时应能分别从目标分类、未分类和全部资产找到它们。

<a id="chapter-05"></a>
## 第05章 标签、评分、备注与批量整理

文件夹回答“放在哪里”，标签回答“有什么特点”，星级帮助你区分取舍。同一素材可有多个标签，但不要用一个过长标签塞进所有信息。练习可以从“山景”“参考”这类清楚的短词开始。

### 5.1 给一份素材添加或删除人工标签

1. 单击一份素材打开详情。如果详情未展开，可右键选择“查看详情”或使用顶部详情栏开关。
2. 在整理区域找到“自定义标签”，点“＋ 创建”。
3. 输入一个标签，点“添加”或按 Enter。等标签出现在列表后，再添加下一个。
4. 删除某个标签时，点该标签旁的 **×**，然后确认它已经从列表消失。
5. 切换到另一份素材再返回，核对刚才的修改。

“自定义标签”是你手动维护的标签，AI 标签属于另一组信息。不要为了删除 AI 标签而反复操作人工标签。侧栏或筛选器中出现的标签可用于找素材，但单纯点击筛选标签不会替当前素材添加标签。

### 5.2 用星级表达你的选择

1. 打开一份素材的详情，在整理区域找到“评分”。
2. 点击想设置的星数，例如第四颗星，等保存结果更新。
3. 需要调整时点击新的星数；再次点击当前星级可清除评分。
4. 回到列表打开高级筛选，选择相应星级，检查素材是否出现在结果中。

评分筛选使用“至少多少星”，例如“3 星＋”会包含 3、4、5 星，不只显示恰好 3 星的素材。评分是人工整理依据，不是 AI 对作品质量的保证。

### 5.3 收录时一次设置标签与星级

对一批用途相同的新文件，可以在导入前统一设置。当前这组规则只适用于主窗口一次 **1–200 个本机文件的 Copy 导入**，不是给任意已选素材一键批量改标签的功能。

1. 打开“导入资源”，选好“导入至文件夹”。
2. 在“本次导入规则”输入一个标签，按 Enter 或点“添加标签”。需要多个标签时逐个添加。
3. 在“人工星级”下拉框选星数；不需要统一评分就保持“不设置”。
4. 点相应文件类别，在系统窗口选择本批文件。
5. 在模式窗口选择 Copy。设置了本批规则后，Link 不可用；要导入目录，应先回到导入窗口清空规则。
6. 导入结束后抽查两份新素材，确认目标、标签和星级都正确。

这些规则只针对本次选择，不是自动分类规则，也不会追溯修改整个资源库。若需要给库内已有素材不同的标签或星级，请分别在详情中编辑。

### 5.4 关于备注和图片描述

当前版本的普通搜索会利用资产已有的备注，也会利用有效的图片描述；但当前主界面**没有通用的资产备注输入、编辑入口**。

AI 图片解读中的“纠正描述”用于修改该图片的解读内容，与原备注分开。需要记录简短分类信息时可使用人工标签；需要表达素材在工作中的用途时可使用项目用途。不要把文件重命名、AI 描述纠正或反馈问题描述当成备注编辑。

### 5.5 可靠地选中一批素材

1. 先进入目标文件夹或设置筛选，让屏幕中主要是本次要处理的素材。
2. 按住 Ctrl 点击不同项，可逐项增加或取消选择；用 Shift 点击可扩展连续范围，也可从空白区域拖出选择框。
3. 要选择当前筛选中的全部素材，先让焦点离开输入框，再按 Ctrl+A。这可能包含屏幕外的结果，不只是眼前一屏。
4. 查看底部“已选中 N 项”，核对数量后，再使用加入项目、导出、删除或右键菜单里的批量操作。
5. 不再操作时点底部“取消”，避免下一次误用旧选择。

多选时详情栏可能收起，这是为了让位给批量操作。文件夹选择和素材选择是不同范围，操作前应确认选中的是哪一种。

### 5.6 批量修改库内显示名

1. 选中 1–200 份素材，在选中项上右键，点“批量修改显示名”。
2. 在“前缀”“后缀”或“字面替换”中设置规则。例如在前缀输入“练习_”，其余保持空白。
3. 需要编号时勾选“顺序编号（加在后缀之后）”，检查起始、步长、位数与分隔符。编号按当前查询的固定顺序生成。
4. 点“生成预览”，逐项对照“当前显示名”和“修改后显示名”。有重名、非法字符、空名等提示时先改规则，再生成预览。
5. 确认无误后点“确认修改显示名”，等待完成，回列表核对。

该功能保留格式后缀，只改 JAMY 库内显示名，**不改磁盘文件名和位置**。规则没有产生变化时也不能确认。若窗口提示选择、查询或资源库已经改变，关闭后重新选择，不要在失效预览上继续提交。

想撤回最近一次已确认的命名，可点提示条“撤销本次命名”，核对恢复预览，再点“确认恢复旧名”。它只在当前库当前会话且条件仍有效时可用；后续写入、切库或结束会话可能使入口失效。若结果是“待核验”，先用“核验原命名操作”，不要再运行一次命名规则。

**常见问题**：标签添加后没有显示时，先看保存提示并重新打开详情；不要连续重复点添加。批量改名按钮不能确认时，检查是否已生成预览、规则是否产生变化，以及有没有同目录重名。

**本章练习**：给两张图加“练习”标签，分别评为 3 星和 5 星。再对两项加“练习_”显示名前缀并检查预览。完成时两张图应能被标签找到，3 星筛选包含两张，5 星筛选只保留其中一张。

<a id="chapter-06"></a>
## 第06章 搜索与组合筛选

素材变多后，先缩小范围，再逐步增加条件，比一次填写所有条件更容易找到问题。搜索和筛选改变的是当前看到的结果，不会移动素材，也不会产生新的文件副本。

### 6.1 先确定在哪里搜索

1. 想找整个库的素材，先点击左侧“全部资产”；只想找某个分类，就先进入该文件夹。
2. 在顶部搜索框输入一个短词，例如文件名的一部分或你添加的标签。
3. 等结果更新，查看底部数量。普通搜索覆盖名称、人工与 AI 标签、已有备注和有效图片描述。
4. 找到候选后点开详情核对内容。需要清空搜索时点搜索框右侧 **×**。

普通关键词搜索与右侧“AI 搜索”入口不同。本章练习无需先配置 AI；没有 AI 描述的图片仍可通过名称和人工标签查找。怎样准备 AI 图片描述及按意思搜索，见 AI 相关章节。

在“项目”页搜索时，范围是当前项目及其下级的素材，不会自动变成全库搜索。返回资产库后也要核对当前文件夹与残留筛选，不能仅凭搜索框为空就认定已经查看所有素材。

### 6.2 组合类型、标签、星级与格式

1. 先进入“全部资产”，清空上一轮关键词；按需要选择顶部素材类型，例如图片。
2. 点“高级筛选”，展开筛选工具栏。
3. 选择“标签”，再选“练习”；等结果更新后，选择“星级”中的 3 星条件。
4. 如需限制文件格式，再打开“格式”选择 PNG 或 JPG。格式清单可以多选，清单和数量以当前读取结果为准。
5. 查看剩余结果，逐张核对；需要放宽条件时，先取消最后增加的一项，或点“重置筛选”。

不同种类的条件会一起生效。例如“图片＋练习标签＋3 星＋PNG”，意味着结果要同时满足这些条件。条件越多，结果可能越少；零结果不等于库中没有文件。

关闭高级筛选工具栏只是收起界面，不表示已经清除条件。重新查找前请留意筛选按钮的状态、当前类型和搜索框内容。

### 6.3 按画面、尺寸、颜色和时间查找

1. 选择图片或包含需要检查媒体的范围，再打开“高级筛选”。
2. 用比例筛选选择横图、竖图、正方形或预设比例；需要更精确时，填写自定义比例及容差，点“应用比例”。
3. 用分辨率筛选选择像素区间；或填写自定义像素上下限，点“应用像素范围”。这里按最长边理解，不等于文件体积大小。
4. 需要按颜色选片时选择色卡，并按结果调整容差。它匹配已提取的色卡；尚未完成色卡提取的素材可能暂时不在结果中。
5. 需要明确日期范围时选“自定义时间”，填写起止日期，再检查结果。时间依据收录记录，不是相机拍摄时间。

“今天”“最近 7 天”等是方便选项。当前“本月”选项按最近 30 天的范围筛选；要查某个自然月，请使用自定义起止日期，避免把两个范围混在一起。尺寸或媒体信息未知的素材，也不应被当成已经符合指定尺寸。

### 6.4 排序与动态选片

1. 筛出一组候选后，点顶部上下箭头“排序”按钮。
2. 按任务选择名称、收录时间、文件大小等顺序。包含图片或视频时可使用分辨率排序；视频时长、模型三角面数等选项依当前媒体类型提供。
3. 检查第一批结果，选中需要的素材，再加入项目或归类。
4. 下次选片时重新设置同样条件，新增素材和新评分会按当前数据参与匹配。

排序只改变先后次序。按分辨率从高到低排列，并没有自动排除低分辨率素材；需要排除时必须同时设置筛选。对没有相应信息的素材，不要仅凭排列位置推断其真实大小或质量。

### 6.5 关于智能文件夹

Windows 3.1.13 当前没有可用的智能文件夹创建、打开或管理入口。本版不能把当前条件保存为智能文件夹。可以先形成固定的组合筛选习惯，每次设置条件得到最新匹配结果；需要长期保存人工挑选的素材集合时，可以加入项目。

**常见问题**：“明明有图却搜不到”时，先回全部资产、清空搜索、重置筛选，再从名称搜索开始逐步加条件。“关掉筛选栏还是只有几张”时，检查条件是否仍然生效。“按颜色找少了”时，先确认色卡是否已提取完成。

**本章练习**：找出所有带“练习”标签、至少 3 星的图片，按名称排序；然后改成至少 5 星。能解释为什么数量变化，再清除条件恢复全部资产，就完成了这一章。

<a id="chapter-07"></a>
## 第07章 项目与素材用途

项目用来记录“哪些素材用于哪项工作”。同一素材可以参与多个项目，不需要为了每个项目再复制一份。文件夹仍负责分类，项目则在分类之外保存归属与用途。

### 7.1 建立一个简单项目

1. 点左侧“项目”，进入项目页面；侧栏收起时先展开项目导航。
2. 在“全部项目”层级点“＋ 新建项目”。
3. 输入名称，例如“秋日短片”，点“新建项目”。
4. 点击新项目进入。需要细分时点“＋ 新建下级”，选择需要的层级并命名。
5. 查看上方路径，确认自己位于正确项目或下级。

可用层级包括项目、章节、场景和镜头，不必每一级都创建。例如可以直接使用“秋日短片 → 场景01 → 镜头02”。“层级（可跳过）”允许只建立实际需要的结构；镜头下不能继续添加更深层级。

第一次练习只建一个项目即可。

### 7.2 把已有素材加入项目

1. 点“去资产库选素材”或切回“资产库”，选择一份或多份素材。
2. 在底部选择工具栏点“加入项目（N 项）”。单份素材也可以从详情中的“项目与用途”进入“加入项目”。
3. 在弹窗中点击已有项目，按需要继续进入场景或镜头，核对“加入到”后面的完整路径。
4. 暂时不需要用途时保持“不指定用途”；需要时展开“设置用途（可选）”并选择。
5. 点底部“加入项目（N 项）”，等待保存结果。
6. 返回项目页面，打开刚才的目标，确认素材出现。也可在素材详情的“项目与用途”核对关联。

加入项目不搬动原文件，也不会替换素材已有的其他项目关系。弹窗提示浏览内容或资源库已变化时，应关闭后重新选素材；如果提示关系已经保存但显示未刷新，先刷新，不要为了刷新列表再次提交。

要一次加入一个分类及其下级素材，可在文件夹右键菜单选择“加入项目（含子文件夹）…”，等待范围读取后核对数量，再选择目标。这里的数量包含子文件夹，可能大于当前画面可见的素材数。

### 7.3 设置和筛选素材用途

用途可以表示图片、视频、音频、文本、模型、动作、参考或提示词。它描述的是素材在项目中的角色，不会把文件转换为另一种格式。“参考”也不表示创建参考画布，“提示词”用途不等于启用一个提示词生成工具。

1. 选择要加入的素材，打开“加入项目”并选好目标路径。
2. 点“设置用途（可选）”，在“本次新增用途”中选一个用途，例如“参考”。
3. 确认加入，等结果完成。
4. 在项目页面顶部“用途”下拉框选择“参考”，查看匹配结果；要查看全部，改回“全部用途”。

用途可不指定，也不会因为新增一个用途就替换原来已有的用途。重复整理时，先查看详情中的现有关联，避免误以为只能保留一个项目或一种用途。

### 7.4 从项目移出与删除项目

从项目移出素材，不等于从资源库删除素材。

1. 打开具体项目，选中要解除关系的素材。
2. 在底部工具栏的“更多”中选“从当前项目移出…”。如果当前按某个用途筛选，也可选“仅移除当前用途…”。
3. 阅读确认窗口里的目标与操作范围，确认是解除归属还是只移除用途。
4. 点“确认移出项目”或“确认移除用途”，等待结果，再查看该项目和素材详情。

这类操作只针对指定层级的关系；素材、源文件以及其他项目的归属保留，下级单独建立的关系也不会被一并当成同一关系移除。因此，父项目仍包含下级素材时，移除父级直接归属后仍可能在父级汇总结果看到该素材。

需要删除整个项目结构时：先进入目标项目，在左侧“更多…”选择“删除此项目…”，阅读包含下级的层级数和涉及素材数，确认后点“确认删除组织关系”。它删除项目及其下级组织关系，素材本身和其他项目归属保留。只想改名称时使用同一菜单的“重命名”，不要删除后重建。

**常见问题**：父项目显示下级素材是正常汇总；请看顶部“项目素材 · 包含下级”。加入后没有显示，先检查是否选错项目层级、用途筛选是否排除了它，再刷新项目。

**本章练习**：建“秋日短片”，把两张练习图片加入并标为“参考”。再仅移除一张的“参考”用途，确认它仍在项目全部用途中，且资源库的文件与标签不变。

<a id="chapter-08"></a>
## 第08章 取用、导出与删除

取用素材前先分清动作：打开调用外部软件，定位显示真实文件位置，导出复制到另一个目录，删除则可能只移除记录，也可能涉及库内文件。需要把素材交给其他软件或别人时，先用少量文件确认结果。

### 8.1 打开、定位与拖出素材

1. 选择一份素材，打开详情，确认文件没有被标记为缺失。
2. 图片、音视频、文本、文档等类型在入口可用时，可点“打开 / 用系统默认程序打开”。实际使用哪个程序由 Windows 的文件关联决定。
3. 想查看真实位置，点“在文件资源管理器中定位”，或从单项右键菜单使用同名操作。
4. 要交给支持文件拖入的软件，可从 JAMY 按住素材拖到目标窗口；多选前先核对所选数量，放下后在目标软件确认是否接收成功。

拖出不等于对方软件已经导入，目标软件是否接受文件取决于它支持的格式与操作区域。文件缺失或磁盘离线时，缩略图仍可能存在，但打开、定位、拖出会受限制。3D 模型需要合适的软件；不能把所有类型都描述为双击即可在 JAMY 全屏打开。

### 8.2 导出所选文件到电脑

1. 在列表选中要导出的素材，查看底部“已选中 N 项”。单次最多 256 项，所选文件总量上限为 2 GiB。
2. 点底部“导出所选文件”。
3. 在系统目录窗口选择保存位置并确认。取消选择会取消本次导出，不开始复制。
4. 等结果提示。成功时显示“已导出 N 个文件到 JAMY_Gallery”。
5. 到刚才选择的位置打开 `JAMY_Gallery`，核对文件数量，并实际打开需要交付的文件。

导出会检查文件名冲突，目标中已有同名文件或本批文件重名时可能拒绝，不能期待它自动覆盖。换一个合适的空目标位置，或调整本批选择后再操作。若结果待核验，或提示只确认复制了部分文件，先检查目标目录，不要立即再导出一次。

“导出所选文件”不是完整项目打包。它不承诺自动收齐模型依赖、外部贴图、项目关系、标签或整库数据；带依赖的文件应在接收软件中验证能否正常打开，需要额外文件时自行一并准备。导出也不是数据库备份。

### 8.3 只把素材从 JAMY 移除

1. 选中准备移除的素材，核对数量；第一次练习只选一份可重新导入的测试文件。
2. 点底部“删除”，或在所选素材右键菜单点“删除”。
3. 在确认窗口保持“将可验证的本地源文件移入回收站”**未勾选**。
4. 点“仅移除索引”，等待完成。
5. 回到“全部资产”检查记录已经移除；若需要确认磁盘文件保留，可到之前记录的真实位置查看。

“仅移除索引”会移除当前库中的资产记录，不等于把素材送到一个 JAMY 内置回收站。后续重新导入也不能保证自动恢复此前的全部整理信息，因此整理分类时优先用“移入文件夹”或“未分类”，不要用删除代替移动。

### 8.4 同时回收库内文件

1. 选择确实不再需要的测试素材，打开删除确认窗口。
2. 仔细阅读提示，再勾选“将可验证的本地源文件移入回收站”。
3. 点“移入回收站并移除索引”，等待本次结果。
4. 根据实际完成数量核对列表；需要确认物理文件时，再检查 Windows 回收站。

该操作只处理符合条件、可核验的库内本地源文件。Link 引用、库外文件以及安全检查未通过的文件会保留，对应索引也会保留。不能把“已选 N 项”当成“N 个文件一定被回收”。出现结果待核验时，使用界面提供的原操作核验入口，不要重复删除。

### 8.5 删除文件夹时怎样选择

在本版新资源库中，右键文件夹选择“删除”会打开“管理文件夹”，有两种主要方式：**解散完整目录树** 移除所选分类及子分类，内部素材仍留在全部资产中；**移除目录树和资产索引** 同时移除这些分类及其资产记录，但仍保留本地文件。

1. 右键目标文件夹，点“删除”，先核对文件夹名称和范围。
2. 只想取消分类结构时，选择“解散完整目录树”。要连同库内资产记录一起移除时，选择“移除目录树和资产索引”。
3. 阅读底部按钮，点“确认解散目录树”或“确认移除目录及资产记录”。
4. 等结果完成，再检查全部资产和原分类位置。

旧版资源库的同类窗口可能出现三种选择：仅解散分类、仅移除索引、同时物理删除。第三项是否出现取决于库类型和内容，不能把它当成本版所有资源库都有的入口。第一次使用不要用整个文件夹练习物理删除；需要回收文件时，先选少量素材按上一节核对。

**本章练习**：先把一张练习图片导出到空目录，打开副本确认正常，再在 JAMY 中对另一张测试图使用“仅移除索引”。完成判断是：导出的副本可打开，被移除的库记录消失，而其原磁盘文件仍在。

<a id="chapter-09"></a>
## 第09章 图片查看与色彩

### 9.1 从缩略图进入大图

在资产列表中单击一张图片，JAMY 会选中它并打开右侧详情。详情顶部的小预览适合快速确认内容；需要检查边缘、文字或纹理时，可以双击图片卡片，也可以点击详情预览上的“查看大图”。选中图片后，底部操作栏还提供“查看所选图片”。

首次使用可按以下顺序练习：

1. 在“资产库”找到一张 JPG 或 PNG，单击后确认右侧显示的是这张图片。
2. 双击卡片，进入图片查看器。
3. 查看完成后，点击左上角“返回”，回到原来的浏览位置。

只选中一张图片时，可以在当前浏览范围内继续切图。希望只比较几张时，按住 Ctrl 逐张选择，再点“查看所选图片”。底部位置与总数显示查看范围；文件夹或筛选条件改变后需重新选择。

### 9.2 放大、移动与连续浏览

底部的“适应”把整图放进窗口，“100%”按源像素与屏幕像素对应检查细节，“适宽”让图片宽度适合当前区域。100% 不表示在所有显示器上都有相同的物理尺寸。

1. 先点“适应”看整体构图。
2. 点“100%”或底部的放大按钮查看细节，也可用滚轮缩放。
3. 图片超出窗口后，在图像区域按住鼠标拖动，移动查看位置。
4. 出现整图导航小窗时，可点击其中的区域快速定位。
5. 点“适应”恢复整体视图，不必反复缩小寻找图片。

底部左右箭头用于切换上一张和下一张；缩略图条按钮用于显示或收起邻近图片。键盘左右方向键也能切图，数字 0 对应适应窗口，数字 1 对应 100%，W 对应适宽，I 切换图片信息，T 切换缩略图条，F 切换全屏。输入标签时，快捷键不会代替文字输入。

点击“全屏”扩大观看区域。Esc 在全屏时先退出全屏，在普通查看时返回列表。也可直接点“返回”。空格可开关查看器，但受输入框、按钮焦点影响，新手先用可见按钮。

### 9.3 边看边做星级和标签记录

图片查看器上方有“星级与标签”区域。你可以直接点星星评分，输入一个标签后按 Enter 或点“添加”，不用先退出大图。成功时会显示“已保存”。再次点击当前星级会清除评分；点击已有标签上的移除按钮会删除这条人工标签。

切换图片后先确认顶部文件名。这里的标记作用于当前图片，不会同时修改全部所选图片。

右侧详情也能完成同样的基础整理：在“整理信息”中找到“自定义标签”，先展开“+ 创建”，输入文字后点“添加”；在“评分”中点击相应星星。人工标签不需要开启 AI，也不会因为尚未生成 AI 描述而失效。

若出现“保存结果待确认”，先使用界面中的“核验保存结果”，或返回列表后重新打开图片核对。标签已经显示在输入框里，不代表已提交；只有实际出现在标签列表并得到保存结果，才算完成操作。

### 9.4 看清透明图片

查看器顶部的背景选择提供“深色背景”“浅色背景”和“透明网格”，同时影响图片缩略图与大图预览。选择透明网格可以判断素材是否带透明区域；深浅背景切换适合检查白色线稿、黑色图标以及透明边缘的残留颜色。

先用浅色背景看深色轮廓，再换深色背景看浅色边缘。背景变化不会给原图填色或改变透明通道。

“图片信息”显示尺寸、格式、大小和所在范围，并可“在文件夹中定位”。图片看起来全白或全黑时，先换背景与缩放比例，再判断文件内容。

### 9.5 提取和使用色板

单击图片后，在右侧详情找到“智能色板”。已有色板会显示主要颜色、色值和比例；尚未生成时可以点“提取色板”，需要刷新时点“重新提取”。提取依据用于浏览的图像内容，因此适合配色参考，不应当作印刷色彩测量或精确像素取样报告。

1. 选中一张色彩清楚的图片，等待小预览正常显示。
2. 点击“提取色板”或“重新提取”。
3. 点击单个色块或色值，将对应十六进制色值复制到剪贴板。
4. 需要一组颜色时，可复制十六进制列表，或点击“CSS”复制为 CSS 变量。
5. 把结果粘贴到自己的设计说明或支持该格式的工具中，并结合原图调整。

界面中还存在 ASE 导出入口；当前手册不把它作为 Adobe 软件兼容交换的操作路径。跨软件使用色板时，先采用已明确的色值复制或 CSS 复制方式。

顶部筛选区的颜色选择可以按已提取的色板寻找相近素材。容差越大，纳入的相近颜色越多。它不是对全库原图逐像素即时扫描：未完成色板提取的素材可能暂时不在结果里，其余色板会在空闲时补齐。结果太少时，可以放宽容差、取消其他筛选，或重新提取目标图片色板后再查。

### 9.6 特殊图片与读取问题

图片浏览范围比 AI 分析更广，但实际显示仍受格式、体积与解码情况影响。PSD 预览不支持逐层编辑，RAW 预览也不等于专业显影；编辑图层或精确色彩处理请用专业软件。

HDR、EXR 可进入全景视口，按住拖动旋转，滚轮缩放。普通长宽比例的 HDR/EXR 不一定适合当作完整环境全景；请结合素材用途判断。将它作为模型环境贴图还需经过另一套大小与分辨率检查，图片能查看不保证一定能用于 3D 环境。

大图可能先显示预览，随后更新清晰度。源文件缺失时先连接磁盘或重新定位；读取失败时确认文件可用，再点“重试读取”。资源受限或格式不支持时，用外部软件查看，或另存较小兼容副本。缩略图仍在不证明原文件此刻在线。

<a id="chapter-10"></a>
## 第10章 3D模型、材质与预览封面

### 10.1 哪些模型可以实时预览

当前实时 3D 预览入口包括 GLB、GLTF、OBJ、FBX、STL、PLY、DAE 和 BVH。具体文件仍需通过读取与解析检查：同一个扩展名可能包含不同导出版本、贴图依赖、骨架或动画数据，不能仅凭格式名称保证每个文件都能完整显示。

BLEND、3DS、ABC、USD、USDZ、UNITYPACKAGE 等当前采用占位展示。它们可以出现在资源管理流程中，但不会因为已经收录就获得原生工程实时渲染。看到格式占位提示时，可以在详情中“在文件资源管理器中定位”，再去对应的 DCC 或引擎软件打开。

带贴图或外部缓冲文件的模型，导入时应保留完整依赖。能显示但颜色异常时先查贴图；无法解析时再查导出格式和文件状态。

### 10.2 打开大预览并调整视角

1. 单击模型卡片，等待右侧详情的小预览加载。
2. 点击详情顶部“大预览”，进入应用内的大预览区域。模型卡片双击通常用于定位文件，不是进入大预览。
3. 在模型区域拖动旋转，滚轮拉近或拉远；需要移动观察中心时可使用鼠标平移操作。
4. 视角偏离模型时，打开“预览设置”，点击“聚焦当前物体”。
5. 需要占满屏幕时点击顶部“屏幕全屏”；结束后点“退出全屏”，再点“返回侧栏”。

“返回侧栏”回到详情小预览；“退出全屏”仍保留应用内大预览。窗口过小时“大预览”可能不可用，扩大窗口后再试。

大预览默认停止自动旋转，便于检查。想看转台效果时，在“预览设置”开启“自动旋转”。这与模型动画播放不同：自动旋转改变观察方式，不会生成或播放模型内部动作。

### 10.3 白模、线框、网格和绘制负载

“预览设置”中的“白模模式”适合检查轮廓和体积，“线框模式”用于观察网格结构，“网格显示”提供空间参考。检查贴图前先关闭白模；界面提示“白模已开启”时，可以点击“关闭白模并查看材质”。

如果模型已加载但转动卡顿，可以尝试“低负载绘制”。它降低预览绘制开销，不会删减源模型，也不保证所有超大模型都能载入。需要对照精细效果时，再切回“标准绘制”。

卡顿时可在“高级诊断”查看并“刷新资源用量”。其中 CPU 几何缓冲、纹理尺寸不等于 GPU 显存占用，不宜直接当作显存报告。

### 10.4 为整个模型或单个材质换贴图

打开“高级 · 材质”，先确认“材质部件槽位”当前选中了什么。“全局材质覆盖”用于整体设置；选择一个具体槽位后，调整的是该部件。多材质模型最好逐个槽位确认，避免把本应只给衣服的颜色图应用到整个角色。

一次贴图试装可以这样完成：

1. 选择目标材质槽位。
2. 在基础色的 Albedo Map 位置选择本机文件，或打开库中的贴图选择器。
3. 贴图选择器可查看模型目录附近的工程贴图，也可切换到全局公共纹理库，通过搜索和格式筛选找到图片。
4. 使用本机新贴图时，按提示决定“复制入库”还是仅建立索引。复制会产生受库管理的副本；索引仍依赖原路径。
5. 回到模型查看变化，再依次设置粗糙度、金属度、法线等通道。

没有相应贴图时，可以直接选基础颜色或调整粗糙度、金属度数值。颜色、法线、粗糙度图作用不同，放错通道可能导致异常颜色、凹凸或反光。

更换透明材质时，在“透明方式”选择适合素材的模式。镂空和半透明会使用颜色图的透明通道；灰度透明图通常以白色表示可见、黑色表示透明。先在一个部件上确认效果，再处理其他部件，避免把整件模型设成意外透明。

普通材质调整自动保存到库记录，不写回原模型。若提示未保存、来源变化或结果待确认，停止连续编辑，恢复库连接后重新打开详情核对。

### 10.5 修复 GLTF 的缺失外部贴图

GLTF 模型的“外部贴图依赖”区域会列出发现的问题。选择替代前先看状态：原贴图缺失、引用不可访问和引用格式不受支持不是同一个原因。不可访问时不应直接判断文件已经丢失。

对明确缺失的贴图，可以点击“选择替代贴图”，从候选中选择；也可按界面提供的入口“选择外部文件并复制到模型 textures”。选择后等待本次预览验证。看到“替代贴图已在本次预览中加载，尚未保存”时，还需要点击“保存替代”。取消则放弃本次候选。

已保存替代可“恢复原引用”。这只修复 JAMY 预览引用，不修改原模型、原贴图或卡片缩略图。源文件变化后需要重新核验。

### 10.6 使用 HDRI 和场景照明

在模型“大预览”的“预览设置”中找到“HDRI 环境”，选择“从资产库选择”或“选择本机文件”，选取 HDR/EXR 环境贴图。环境加载成功后可以调整亮度、方向、背景模糊和背景透明度；不需要时点击“移除”。

HDRI 与“场景照明”分开控制。先固定材质，再调环境方向观察反光，最后调场景照明。两处亮度同时过高会遮蔽细节，宜逐项调整。

视角、网格、白模、线框、照明和环境等预览设置会保存到当前模型的库记录。调整后关注“正在保存预览设置…”和“已保存”。若提示设置未保存，恢复连接后再调整并核对；若提示结果待确认，应完成恢复检查并重新打开预览。自动旋转属于观看偏好，不能把它当作模型动画或交付内容。

环境图过大时，改用较低分辨率的 HDR/EXR；低负载绘制不会取消环境读取限制。

### 10.7 把预览变成容易识别的封面

模型的资产缩略图和文件夹封面是两个步骤：先为模型保存好看的缩略图，再决定是否用它代表所在文件夹。

1. 将模型转到容易识别的角度，调整材质、灯光和背景。
2. 如果模型正在播放动画，先暂停在合适位置。
3. 打开“预览设置”，点击“渲染提取缩略图”，等待保存完成。
4. 返回列表，确认模型卡片显示新的预览。
5. 模型位于可设置封面的文件夹内时，可右键卡片选择“设为文件夹封面”；也可右键文件夹选择“选择封面…”，从可用候选中选取。

保存缩略图不会改变模型几何，也不是导出一段转台视频。只调整材质或灯光，不会自动把旧缩略图全部重做。静态降级预览中提取缩略图可能被禁用，应以当前界面的可用状态为准。

### 10.8 模型预览不成功时

先看提示究竟指向格式、源文件、外部依赖、动画还是资源限制。源文件离线时先恢复路径；缺贴图时检查完整依赖；模型能静态显示而不能播放时，继续按第11章检查动画条件。不要把所有问题都归因为“模型坏了”。

无法处理的数据可在原制作软件检查并导出兼容副本。当前没有已交付的 Blender 插件、DCC 双向同步或原生工程自动修复；可用衔接是选材、预览、定位，再在外部软件打开。

<a id="chapter-11"></a>
## 第11章 骨骼、动画与保存姿态

### 11.1 先判断模型包含什么

角色可能只有网格、有骨架但无动画，或含多段动画。只有解析出可用片段才出现动画控制；姿态功能还需要可靠核验骨架与模型来源。

BVH 等动作文件可以以骨骼方式显示。带骨架的模型可在“预览设置”→“显示内容”中选择模型、骨骼或“模型＋骨骼”；具体选项按文件内容提供。仅有骨骼的文件不会凭空出现角色外形。

### 11.2 播放、切换和检查动作

1. 单击带动画的资产，进入“大预览”。
2. 打开“3D 动画控制”面板，点击播放按钮。
3. 有多段动画时，通过片段选择框切换需要检查的动作。
4. 用 0.5x、1.0x、1.5x、2.0x 调整播放速度。
5. 暂停后拖动进度条，观察脚底、手部、接触位置等关键帧。

播放速度只影响预览。动画默认可用空格播放/暂停，但焦点在输入或其他控件上时应使用播放按钮；图片查看器的空格行为不同。

部分动画可启用“无缝循环修剪”，用于观察循环衔接。它是预览播放设置，不会剪掉源动画帧，也不会导出一个修改后的动作；BVH 不提供这一按钮。需要正式剪辑动作时，仍应回到动画软件。

### 11.3 用骨骼显示检查动作

在“显示内容”中选“模型＋骨骼”，可以同时看模型形变与骨骼位置；选“骨骼”则更容易看清动作结构。打开“简化骨骼”后，预览会隐藏已识别的辅助骨骼和手指细节，让主要动作更清楚。

简化仅影响显示，不删除真实骨骼，也不会改变动画。未识别的骨骼会保留；出现“未识别到可隐藏的辅助连线”时，说明当前文件没有可按这套规则隐藏的连线，不表示操作失败。

角色运动到画面边缘时，可在预览设置点击“锁定跟随物体”，或暂停后“聚焦当前物体”。检查固定机位时留意是否仍在跟随动作。

### 11.4 保存、应用和管理姿态

保存姿态适合记录当前模型的某个动作瞬间，例如挥手最高点、起跳前准备或角色站姿。

1. 播放或拖动动画进度，停在要保留的位置。
2. 打开“姿态/混合”，在“骨骼姿态”中输入便于辨认的名称。
3. 点击“保存当前姿态”，等待保存结果。
4. 之后在姿态列表中点击“应用”，恢复该姿态供观察。
5. 需要继续播放时，点击“返回单动画”。

同名保存会要求“确认覆盖”，也可取消；已有条目可以删除。建议按动作内容命名，方便找回。

姿态保存在库记录中，不导出外部姿态文件或新增动画，也没有通用逐骨骼摆姿编辑器。以保存结果和重新打开后的列表为准。

### 11.5 试用同模型的动画混合

同一个当前模型具有至少两段兼容骨架片段时，“姿态/混合”会出现“同骨架动画混合”。先选主动画，再从“混合动画”选择另一段，移动“混合权重”观察不同占比。选回“单动画”可以结束这次混合。

这用于比较片段叠加的观感，不执行跨模型骨架重定向。没有兼容片段时混合区不会出现。混合也不会烘焙、导出新动作；正式制作仍在 DCC 中完成。

### 11.6 姿态失效、动画过大与静态预览

源模型变化后，旧姿态可能不兼容。“重建姿态库”会删除旧姿态，确认不再需要后再执行；重复点击“应用”不能绕过兼容检查。

骨骼层级、帧数、采样量或准备时间超过预览安全范围时，播放可能停止。部分情况可以使用静态预览，但此时动画不可用，部分保存能力也会关闭。可尝试关闭其他高负载工作、使用较轻的兼容导出副本，或回原制作软件检查空动画轨道等问题。

出现“姿态保存结果待核验”时，停止继续添加或覆盖姿态，先恢复资源库状态。若提示“姿态已保存，但资源库刷新失败”，重新打开详情核对记录，不要立即建立一个同名副本。

## 第12章 视频、音频、文本与文档

### 12.1 视频先预览，再交给剪辑软件

单击视频资产，在右侧预览区域使用播放器自带的播放、暂停、进度和音量控件。JAMY 为 MP4、WebM、MOV、AVI、MKV、M4V 等提供视频预览路径，但容器格式与内部编码是两回事；文件能被收录，不保证播放器能解码其中的所有视频和音频编码。

1. 选中视频，等待播放器读取基本信息。
2. 点击播放，确认画面与声音是否正常。
3. 拖动进度条查看关键片段，停止后核对详情中的名称与文件位置。
4. 在“视频编码信息”查看分辨率、帧率、编码和时长。未获得可靠信息时可能显示“未知”。
5. 需要完整编辑或 JAMY 无法播放时，使用“打开 / 用系统默认程序打开”，或先定位文件后交给剪辑软件。

时长和分辨率可能在载入后补齐。“未知”不是零，缩略图成功也不等于整段可播放。当前不提供剪辑、转码、字幕制作或视频逐帧 AI 分析。

### 12.2 用波形定位音频

MP3、WAV、OGG、AAC、FLAC、M4A 等进入音频预览。单击资产后，右侧显示“整段音频”、波形或已有音频缩略图、播放进度与时长。

点击播放按钮试听；在波形区域拖动播放进度，可跳到目标位置。右下角可调整音量，点击扬声器按钮静音或取消静音。音频时长尚未读出时，进度拖动暂不可用，先等待元信息加载。

试听后可添加标签和星级。波形只辅助定位，当前没有裁切、多轨混音、自动转写或节拍分析入口。

音频无法播放时，确认源文件在线后点播放重试；也可用默认播放器检查文件或编码。

### 12.3 阅读文本和代码

TXT、MD、Markdown、JSON，以及常见脚本和代码文件可进入“文本预览”。单击后，顶部会显示格式、“只读文本”和识别到的编码。你可以滚动阅读、选择文字复制，点击“刷新”重新读取当前文件。

文本最多显示前 256 KB，超出部分用外部编辑器查看。这是显示范围，不是文件被截短；空文件会明确显示“空文件”。

Markdown、HTML 和脚本在这里按文本查看。预览不运行脚本，也不等于浏览器渲染后的网页或排版后的文档。修改内容请使用“打开 / 用系统默认程序打开”，在合适的编辑器中完成；回到 JAMY 后再刷新检查。

乱码或读取失败时，先在外部编辑器确认内容与编码，再检查路径、库连接并刷新。

### 12.4 区分文档管理与文档阅读

JAMY 中的“文档”类别并不表示内置了完整 Office 或 PDF 阅读编辑器。当前明确的文档正文入口是上述只读文本预览；对未提供可用预览模块的文件，应使用外部程序。

制作说明仍可加入项目、添加标签和评分，搜索后定位取用；这不代表所有二进制文档正文都能解析或进入图片 AI 分析。已有备注可以参与搜索，本版不提供通用的备注编辑入口。

### 12.5 把不同媒体组成项目资料

可把场景图、参考视频、音效和说明加入同一项目并指定用途，再按星级挑选。项目不搬动文件，每种素材沿用自己的预览。外部索引的原磁盘被移动或拔出后，即使封面仍在，也应先恢复源文件再播放、读取。

<a id="chapter-13"></a>
## 第13章 AI配置与图片分析

### 13.1 开始前先选对能力

在设置中进入“AI 分析与搜索”。当前可用来源是“本地 AI”和“自定义 API”；“JAMY 云端服务”尚未开放，不能在本版本中购买或启用官方云端调用。

图片分析负责看图并生成描述与标签；AI 搜索负责整理已有描述、标签、备注。两项要分别配置和检查：一项通过不代表另一项通过，搜索可用也不表示已经分析全部图片。

当前图片分析支持静态 PNG、JPEG、WebP。GIF 动图、视频、音频、模型、文档等不能因为出现在库中就获得图片识别。其他图片格式需要分析时，可在外部软件另存兼容的静态副本，再导入。过大的图片还可能触发安全处理限制，必要时使用降低分辨率的副本。

AI 功能处于 Beta 阶段，颜色、数量、人物动作和小物体可能描述不准。先拿几张自己熟悉的图片检查效果，再决定是否扩展到整个文件夹或全库。

### 13.2 使用 JAMY 管理的本地 AI

适合希望在本机运行、暂不连接第三方图片分析 API 的用户。首次需要下载运行组件和推荐模型，完整下载约数 GB，具体总量与缺少项以界面为准。

1. 在“AI 来源”选择“本地 AI”。
2. 保留“由 JAMY 管理本地组件（推荐）”。它位于“高级设置与组件位置”中，通常无需修改。
3. 如果出现“下方更改尚未应用”，点击“应用 AI 设置”。
4. 点击“准备本地 AI”，查看当前组件、文件进度、已下载字节和速度。
5. 等待组件就绪；下载完成后还会校验与安装其他缺少项，不要把某一个文件的 100% 当作全部准备完毕。
6. 分别点击“检查图片分析”和“检查搜索”，确认各自显示“测试通过”。

准备期间可以继续浏览素材。需要中断网络下载时用“暂停准备”；以后点“继续准备”保留已有进度继续。失败时先看当前阶段与原因，再用“重试准备”。首次下载来自运行组件和模型的官方来源，当前没有切换镜像的设置。

同电脑、同 Windows 用户更新软件后会沿用组件，换电脑需单独准备。高级设置可查看模型位置；复制资源库不等于迁移模型。

### 13.3 已有 Ollama 服务与运行速度

如果本机已经安装并运行 Ollama，可在高级设置中取消由 JAMY 管理组件，填写“已有 Ollama 服务端口”、图片模型和“搜索模型（1024 维）”。自选模型必须已经存在，并分别通过图片分析和搜索检查。不要只改模型名字就假定系统会自动下载那个自选模型。

修改后先应用，再分别检查。“服务已连接，尚未验证”不等于模型测试通过；图片输入、结构化输出和向量维度仍需满足要求。

本地运行前会检查可用内存。显示内存不足时，可以关闭占用较高的程序后再试；通过最低检查也不保证每张图片都很快。首次加载、模型大小、图片内容及 CPU/GPU 条件都会影响耗时。

连接检查结果会尽量显示实际使用的是 CPU、GPU 加速、GPU＋CPU，或“设备未确认”。不要仅凭显卡存在就判断正在用 GPU，也不要把未确认状态当成 CPU。当前没有保证所有显卡都能加速、每张图片固定几秒完成的承诺。

### 13.4 连接自己的 API

选择“自定义 API”后，需要已有服务商账户、可用密钥和符合要求的模型。服务须兼容 OpenAI 风格的聊天补全图片输入与文本向量接口；任意网页聊天地址不能直接接入。

1. 填写“服务地址（Base URL）”，使用服务商提供的接口基础地址，通常带有版本路径；不要粘贴控制台、充值页或聊天网页地址。
2. 填写 API Key。界面显示密钥已保存时，留空会保留原密钥。
3. 填写“图片分析模型”，确认支持图片输入与 JSON 输出。
4. 填写“搜索模型”，确认支持 1024 维文本向量。能聊天、能看图不等于能生成搜索向量。
5. 首次保留默认“同时分析图片数”2。确认稳定后，才考虑在 1—4 之间调整。
6. 阅读接收端点与数据发送说明，勾选授权，再点击“应用 AI 设置”。
7. 分别执行“检查图片分析”和“检查搜索”，查看明确的测试结果。

远程地址需要使用 HTTPS；本机回环服务有单独的 HTTP 支持。地址发生重定向时可能被拒绝，请填写服务商给出的最终接口地址。图片模型和搜索模型可以来自同一服务，但不应因为名字相似就填成同一个模型；是否兼容以能力检查为准。

占位示例不代表已有调用权限或效果保证；模型、购买与计费以实际服务为准。

### 13.5 数据、费用和撤回授权

使用自定义 API 分析图片时，会发送处理后的图片与任务指令；准备 AI 搜索时，会发送用于索引的 AI 描述、人工纠正内容、标签以及素材备注等文本；查询时会发送搜索词。请求还带有鉴权密钥和必要网络信息。检查连接也可能产生服务商费用。

勾选授权针对数据发送和服务调用，不是模型训练开关。留存、训练用途与接收地区应查看服务商条款及账户设置；发送保密图片前先确认自己有相应授权。

“每日请求次数上限（UTC）”按 UTC 日期控制请求次数，它不是人民币、美元或其他货币的金额上限。提高同时分析数量只是增加并行请求，不保证单张更快；限流时会等待并自动降低并发。本地 AI 仍逐张分析。

要撤回 API 授权，取消勾选后必须点击“应用 AI 设置”；只取消勾选但未应用时，原配置仍生效。也可使用“停用 API 并移除密钥…”并完成应用。未发送任务可以保留，已发送请求和已经产生的费用无法撤回。切换服务后，已有自动分析、未完成任务和搜索会受新配置影响，操作前先查看待办。

### 13.6 先分析一张图片

检查通过后，选中静态图片，在右侧“AI 图片解读”点击“分析图片”。期间可继续浏览，完成后回到此图核对保存的描述和标签。

1. 选择主体清楚、内容熟悉的图片，确认原图正常显示。
2. 点击“分析图片”，不要重复建立相同请求。
3. 查看生成描述，逐项核对主体、场景和关键细节。
4. 查看“关于这次分析”，了解模型与完成时间。
5. 判断结果可用后，再按第14章处理标签、纠正描述和批量任务。

已有结果时按钮会变成“重新分析”。这会再次运行分析，不是刷新显示；只想看当前状态时应点旁边的刷新图标。重新分析不等于一定更准确，重复使用同一模型也可能得到同样的误判。

### 13.7 配置或分析失败时怎么处理

提示未找到模型时，检查名称并准备组件；本地服务未连接时，检查服务与端口；密钥或权限错误时，在服务商控制台确认权限后重新保存配置。显示“设置尚未应用”时，先应用，再测试，避免实际调用仍使用旧配置。

模型输出不完整时，新结果不会按成功保存。图片来源改变时，旧分析可能被隐藏，应重新选择当前图片后再分析。文件不支持或超过处理上限时，用兼容静态副本验证，不要一直重试原文件。

网络中断或 API 超时可能意味着服务商已经处理、但 JAMY 没有收到确定结果。此时自动调用可能暂停，应先检查服务记录和费用，再按界面恢复，不要连续点击增加不确定请求。本地分析超时也应按页面提示等待后重试。出现保存结果待确认时，关闭并重新打开详情核验，勿把重复分析当作保存修复。

## 第14章 AI标签、搜索与任务

### 14.1 AI 标签与人工标签各做什么

AI 标签在分析成功后会自动参与搜索与筛选，不需要逐张确认才生效。人工标签位于“自定义标签”，用于你自己的项目词汇、用途和管理习惯。可以保留 AI 的“山地”“建筑”等内容标签，同时增加人工“片头备选”“客户已选”等工作标签。

在图片详情的“AI 图片解读”中点击一个 AI 标签，会出现相应操作。选择“修改”后输入正确文字，点“保存纠正”；不需要的建议可“移除 AI 标签”；希望纳入人工标签体系时可“转为人工标签”。“识别有误”用于标记错误建议。不同操作含义不同，不要为了让标签能搜索而把所有 AI 标签一律转成人工标签。

处理后可查看“修改记录”，有“撤销上次审核”时可撤销最近操作。要求刷新后再审核时，先刷新，避免覆盖较新的修改。

### 14.2 纠正图片描述

当主要内容认错、颜色遗漏或机器描述不适合搜索时，在详情点击“纠正描述”。输入能准确说明画面的文字，点击“保存纠正”。这项操作不会改动原备注，也不会训练出一个新的模型。

例如把“风景”补充为“黄色沙丘，远处有低矮山脊，画面中没有人物”。写可见事实，少写推测；具体描述有助搜索，但不保证每次精确命中。

界面提示原机器描述已停用时，应补充正确描述。修改后先确认详情显示你的纠正，再等待搜索整理同步；如果立即搜索没有更新，可以到右下角“任务”查看近期修改是否仍在处理。

### 14.3 对已有图片建立批量任务

主界面工具栏的“AI 分析任务”可打开批量窗口；选中素材后，底部“AI 批量处理”也可进入。设置中的“分析素材与管理任务”提供同一工作入口。

1. 先选择几张图片，或进入要处理的文件夹，再打开任务窗口。
2. 在“范围”中确认是所选资产、当前文件夹/当前视图，还是整个资源库。按需勾选“包含子文件夹”。
3. “操作”选择“分析图片”。默认跳过已有有效结果；确实要重做时才勾选“重新分析已有有效结果（默认跳过）”。
4. 点击“下一步：确认数量”，等待统计完成。
5. 核对可处理、已跳过和异常数量，再点击“开始任务”。
6. 关闭任务窗口继续浏览，通过右下角“任务”查看进度。

确认数量只检查范围，仍需点击“开始任务”。可处理为零时查看“跳过与异常详情”：可能已有有效结果，也可能是缺失、不支持或来源变化。总数不等于实际发送数量。

批量标签处理沿用同一窗口。“纠正 AI 标签”需要填写原标签和正确标签；“移除 AI 标签”“转为人工标签”需要指定原标签。先用小范围确认效果，再扩大范围，避免把项目中含义不同的同名标签一起修改。

### 14.4 新图片自动分析

在 AI 设置下方开启“自动分析本库新导入图片”，只处理开启后导入当前库的新图片；旧素材仍需建立批量任务。

大量导入前，先确认当前使用的 AI 来源、模型和费用授权。自动分析使用已应用配置，切到自定义 API 后，后续任务可能发送给该服务。需要暂停时点“暂停分析”，恢复时点“继续分析”；“取消当前待办”用于取消尚未发出的工作。

暂停或取消后不再发送新的图片请求，但已经发送的图片仍可能完成并保存，已有结果也会保留。关闭任务窗口不会停止任务；重新打开软件后，应检查实际显示的待办与暂停状态，不要因为窗口关闭就认为任务已经取消。

### 14.5 准备 AI 搜索与按意思查找

图片分析完成后，搜索模型还要把描述、标签和备注整理成搜索数据。在设置底部“准备 AI 搜索”中查看状态；尚未启用时点击“准备 AI 搜索”，暂停时点击“继续准备”。右下角“任务”也会显示这类进度。

这一步不重新看图。描述修改会同步；更换搜索模型会重整搜索数据，保留标签与人工修正。自定义 API 的整理也会产生服务商请求费用。

状态就绪后，可按下面的方法搜索：

1. 在顶部搜索框输入简短描述，例如“海边的日落”。
2. 等输入完成，点击旁边“AI 搜索”。普通输入自动筛选与 AI 搜索按钮是两种操作。
3. 等待结果，查看是高相关匹配、相近候选，还是无结果。
4. 单击或打开大图核对内容，尤其检查颜色、数量和细节。
5. 想回到普通搜索时，在搜索说明中点击“只用关键词”。

AI 结果按相关度排序，退出后恢复普通排序。当前的文件夹、项目或其他筛选仍可能限制显示范围，AI 搜索不会自动清除所有筛选。出现相近候选不代表完全满足描述；描述过长时请缩短，当前输入上限为 512 个字符。

单库 AI 搜索目前最多处理 20 万项内容。这是 AI 搜索处理范围，不是资产导入上限。超过范围、缓存受限或搜索模型不可用时，仍可暂用关键词搜索和现有标签组织素材。

### 14.6 用 AI 标签缩小范围，再回到关键词

工具栏“AI 标签筛选”会列出全库已分析素材的标签及匹配数量。点击一个标签即可筛选；列表很多时可翻页，结果变化时点“刷新”。没有标签时，可从“去分析素材”开始建立图片分析任务。

标签数量来自全库，当前页面的文件夹、类型或评分条件会进一步缩小结果。点击标签筛选旁的 × 可清除该条件；无结果时先检查筛选。

普通搜索可查名称、人工与 AI 标签、备注和有效图片描述。已有“片头备选”标签时，直接输入即可；无需点 AI 搜索或等待模型就绪，中文完成选字后列表自动更新。

颜色可结合色板筛选，用途可结合人工标签与评分。检索不到图片不代表文件丢失。

### 14.7 管理等待、暂停、失败和不确定结果

点击右下角“任务”打开“资产任务”，先辨认任务名称。图片分析在生成描述和标签；“准备 AI 搜索”在整理可检索内容。两者都可能等待本地模型、内存或服务额度，暂停其中一种不必然等于暂停另一种。

批量任务有“暂停后续任务”“继续”和“取消剩余任务”。已确定失败的条目可用“重试确定失败项”；显示结果待核验时，应先点“核对原任务”，不要直接另建相同批次。取消剩余任务不会删除此前完成的描述、标签或原文件。

限流时查看最早继续时间、降低并发或检查额度；请求达上限时等下一 UTC 日期或调整上限。模型、密钥错误先回设置修复。

搜索准备可以“暂停准备”，完成部分会保留，重开后仍保持暂停；需要继续时手动恢复。显示“正在同步近期修改”时，先等待整理，不必重新分析所有图片。准备失败但源文件仍可浏览时，可以点击“只用关键词”继续工作。

先分析少量已知图片，纠错并等搜索就绪，试真实需求后再扩展批次；每次确认范围与当前服务，分别处理质量、索引、筛选和文件问题。

## 第15章 Quick 快捷收集

### 15.1 打开 Quick，确认当前资源库

Quick 是一个可以浮动或贴在屏幕边缘的小窗口，适合在浏览资料、整理下载文件或连续导出素材时，少切换几次主界面。它能收录文件，也能搜索当前资源库。第一次使用前，先在 JAMY 主界面连接好准备存放素材的资源库。

按 `Ctrl+Alt+J` 唤起 Quick，或点击主界面侧栏的“快捷窗口”。也可以进入“设置 → 导入与快捷窗口”，点击“显示 / 找回快捷窗口”。找回操作会把窗口带到当前屏幕的浮窗位置，保留尚未提交的草稿。如果快捷键被其他软件占用，仍可使用侧栏、设置或托盘入口。

打开后先看“收录位置”：这里同时显示资源库名称和收录目录。默认目录是“收件箱”，适合先集中保存、稍后整理。不要仅凭主界面刚刚浏览过的文件夹，推断 Quick 一定会存到那里；以 Quick 显示的目标为准。

需要更换目录时，点击“收录位置”右侧的“更改”，在“收录目录”中逐层进入并选择目标，再确认。更换同一资源库中的目录，会保留本批文件、标签和星级。若要更换资源库，切换到相应选择页，选择可用的库再确认；这会同步切换主界面，并清空本批文件、标签和星级，所以应先完成或放弃当前草稿。

### 15.2 收录一批本机文件

Quick 的本机文件入口每批支持 1～200 个不同的普通文件，采用“复制入库”。如果希望只建立索引，或要导入整个目录，请回到主界面的导入入口选择相应方式。

1. 从 Windows 资源管理器选中文件，拖到 Quick 的收录区域；也可以点击“拖入文件，或点击选择”。
2. 等待出现文件数量、名称和可用预览。检查是否选对文件；需要调整时点击“重选”，放弃本批时使用清空按钮。
3. 再次确认“收录位置”。需要归入项目时，使用本批显示的项目选择入口；不需要时保持未选择。
4. 如需统一标注，展开“标签”，输入以逗号分隔的标签，也可选择出现的标签建议。星级是可选项，点击一至五星；选错可用“清除星级”。这些规则作用于本批收录。
5. 点击“收录 N 项”。准备好文件或出现预览不表示已经入库，必须查看提交后的结果。
6. 完成后检查“已收录”“跳过”“失败”等数量，必要时打开“查看详情”，再到主界面核对目标目录。

复制成功的文件会占用资源库所在磁盘的空间，源文件仍留在原位置。重复内容可能被跳过，因此选中数量与新增数量不一定相同。跳过也不等于复制失败，应在逐项结果中确认具体状态。

部分格式不能在 Quick 中生成缩略图，或文件太大、预览服务正忙时，窗口可能只显示文件占位信息。只要提示允许继续收录，就可以按正常流程提交；预览结果和收录结果要分开判断。若提示“文件已变化”，先等待原软件完成保存，再重新选择，避免将仍在写入的输出文件作为最终版本收录。

Quick 也能接收部分浏览器拖出的图片。首次从网页收集时，按出现的网页导入说明确认；网页是否允许下载、浏览器提供的是图片还是链接，都会影响结果。遇到不支持的拖动内容，可以先将图片合法保存到本机，再按本节收录，不能把本机每批 200 个文件的规则直接套到所有网页拖入场景。

### 15.3 用 Windows“发送到”接入 Quick

“发送到 JAMY Quick”默认关闭，需在已安装的 Windows 桌面版中启用。

1. 打开“设置 → 导入与快捷窗口”。
2. 在“发送到 JAMY Quick”卡片点击“启用发送到入口”。
3. 回到资源管理器，选中本机文件，通过右键菜单的“发送到”选择 JAMY Quick。
4. 在 Quick 查看收到的批次。如果显示“接收文件”，点击它，将文件放入收录区。
5. 核对目标、标签和星级，最后点击“收录”。

接收文件只是准备草稿，不会跳过最终收录确认。Quick 已有草稿时，新批次不会覆盖原来的文件和规则；先处理当前草稿，再接收新的一批。如果不需要新批次，点击“忽略此批”。请求过期或文件已经改变时，从资源管理器重新发送。

如果提示同名入口属于另一套 JAMY，软件不会替你覆盖它。先确认正在使用哪一套安装，再处理入口。以后不需要该功能，可在同一设置卡片点击“移除发送到入口”。

### 15.4 监控渲染或导出目录

“监控文件夹”适合从其他软件不断导出图片、模型等文件的工作。它发现文件后放入 Quick 待收列表，仍由你确认复制入库。

1. 准备一个本机普通文件夹，作为渲染或导出位置。避免选择资源库、程序、配置目录及其上级；网络目录、映射网络盘或包含特殊链接的目录可能无法使用。
2. 进入“设置 → 导入与快捷窗口 → 监控文件夹：发现新导出文件”，点击“选择目录并开始”。
3. 确认卡片显示的目录和绑定资源库正确，再从制作软件向该目录导出文件。
4. 等制作软件完成写入，在 Quick 的“输出目录”待收提示中点击“接收目录文件”。
5. 核对文件和目标，点击“收录”。只想忽略这一批时，使用“忽略目录此批”。

监控只查看所选目录的顶层文件，不递归处理子文件夹。首次启用时已经存在的文件不会自动收录；后续新文件或观察到的文件版本变化才会进入待收流程。“一段时间没有变化”也不保证制作软件已经输出完成，应以导出软件的结果为准。

重启 JAMY、切换资源库或目录断开后，监控会暂停。需要继续时，回到原资源库，在设置中点击“重新确认原目录并恢复”。“刷新监控状态”只更新这里显示的情况；它不等于重新收录文件。

待处理达到 200 项时，先清理 Quick 中的待收和失败项。目录超过 2048 项也可能暂停监控，适合另选较小的当期导出目录。失败或取消的文件，需要在设置中明确点击“重试未成功文件”。“停止并清除未确认待收”结束这次监控并清除尚未确认的待收信息，不应理解为删除原导出文件或已入库素材。

### 15.5 查结果、搜索和取用

点击“最近收录”可以按批查看结果。打开一批后，可看到已收录、跳过、失败、取消和待处理数量，以及逐项结果。显示“结果待确认”时，先点“刷新结果”；原任务未结束且提供“恢复”时，恢复原批次。不要把“结果未确认”直接当作失败，再次完整提交同一批。

“取消未完成项”针对尚未完成的部分，已经保存的素材会保留。若已有多批需要确认，Quick 会要求先处理这些批次，再开始新收录。

需要取用素材时，点击 Quick 顶部的“搜索”，输入名称、描述或标签关键词。搜索覆盖当前库的所有目录，采用关键词前缀匹配，多词需要同时满足，每页最多显示 12 项；它不是主界面的 AI 语义搜索。结果较多时使用“下一页”，需要重查时点击“回首页 / 重试”。

选中可用结果后，可以“复制路径”“在文件夹中显示”，或在支持时“打开”。复制路径得到的是文字路径，不是文件副本。允许拖出的结果可以拖向其他软件，但目标软件是否接收由它决定，关联文件不会随主文件自动打包带走。按钮不可用时，先检查文件是否离线、类型是否支持，再回主界面处理。

### 15.6 调整贴边位置

Quick 顶部可选“浮窗”“左停靠”“右停靠”。贴边后开启“离开后自动收起”，窗口会缩为把手；点击或靠近把手可以展开。有草稿或操作进行时，窗口可能保持展开，便于完成确认。

收起后可拖动把手底部的拖动柄上下调整位置。自动收起与“隐藏全部”不同：前者保留把手，后者需要再次唤起。窗口找不到、移到另一块屏幕或快捷键无响应时，优先用主界面侧栏或设置中的“显示 / 找回快捷窗口”。

## 第16章 手机传图与局域网传输

### 16.1 传输前的准备

手机导入适合把手机上的照片、视频等文件发送到正在运行的 JAMY。手机和电脑需要能够在同一局域网内互相访问，电脑上的目标资源库也必须可用。首次使用建议先传一张普通照片，确认整个流程后再传大批文件。

当前传输使用 HTTP，没有 HTTPS 传输加密。请使用自己信任的家庭或工作网络，不在不可信的公共网络操作，也不要公开二维码或带配对信息的连接地址。扫码配对用于确认连接，不等于对传输内容加密。

### 16.2 先允许，再启动本次传输

1. 在主界面确认当前资源库和准备存放的位置。
2. 点击侧栏的“手机导入”。如果出现“尚未允许局域网传输”，点击“前往设置开启”。
3. 在“设置 → 导入与快捷窗口 → 局域网移动端传输”打开开关。
4. 返回“手机导入”窗口，此时应显示“已允许传输 · 尚未启动”。
5. 点击“启动本次传输”，等待电脑显示二维码、连接地址及本次传输信息。

设置开关只是允许使用该功能；打开窗口也不代表已经开始监听。只有明确启动本次传输，手机才有可连接的会话。若设置开关已打开但没有二维码，应回到手机导入窗口检查是否还未启动，而不是反复切换网络开关。

### 16.3 扫码、配对和上传

1. 用手机扫描电脑上的二维码，在手机浏览器打开连接页面；不能扫码时，可按页面提供的完整连接地址访问。
2. 手机请求连接后，电脑会显示验证码。核对它与手机上的验证码一致。
3. 确认是自己的手机后，在电脑点击“允许本次传输”；不认识的请求点“拒绝”。
4. 在手机网页选择文件并开始传输，保留页面，等待每个文件的传输结果。
5. 回到电脑检查入库结果，再打开新收录素材，确认内容完整。

电脑会显示剩余文件数量、容量及到期时间。单个文件最多 16 GiB，传输速度取决于网络和两端设备；大文件更适合分批发送。超过单文件上限时，改用电脑端导入，不要把传输上限误当成所有文件都能在 JAMY 中顺利预览的保证。

手机端如提供“取消本批次”或“重试失败 / 未发送文件”，先根据逐项结果操作。取消后，先前已传到电脑的文件不会因此自动撤回。不要因为最后一项失败，就把已经成功的整批再次发送。

### 16.4 “已传到电脑”之后还要核对入库

手机显示“已传到电脑”，只代表网络传输完成，电脑端还需要完成资源库收录。通常会继续进入入库流程，但资源库忙、连接变化或收录尚未完成时，可能需要你继续处理。

如果素材没有立即出现，先查看电脑主界面底部的“任务”。出现“手机导入”及“手机文件已接收，等待入库”时，展开并确认提示中的目标位置，然后对相应文件点击“继续导入”。以电脑确认的收录结果和目标目录中的实际素材为准。

文件已收录但列表中找不到时，核对当前资源库、目录、搜索词和筛选条件，必要时刷新当前列表。不要只凭手机端的“完成”就删除手机原件；先在电脑打开文件确认一次，尤其是视频和较大的文件。

### 16.5 停止传输与常见连接问题

完成后，在电脑点击“停止传输”，再关闭手机页面。关闭电脑上的手机连接窗口也会结束相应传输；传输中请不要把关闭窗口当作普通后台隐藏操作。

扫码打不开时，依次确认：电脑仍显示有效连接信息；两端在可互通的同一局域网；电脑允许这次局域网连接；网络没有将无线设备彼此隔离。不要为了传文件直接关闭整台电脑的防火墙。连接过期时重新启动并扫描新二维码，旧地址不应继续当作长期入口。

如果显示“资源库当前不可用”，先恢复资源库连接，再启动传输。如果显示“服务权限已撤销，但传输清理尚未确认完成”，按窗口的“重试安全收尾”处理；此时软件阻止重新启动，是为了先完成上一轮收尾，不要手动删除临时文件强行绕过。

## 第17章 目录同步与文件变化

### 17.1 明确目录同步跟踪什么

“目录同步”位于“设置 → 存储与资源库”。它跟踪库内副本和已经关联的外部索引目录，将新增、修改、改名和移动等变化反映到资源库，尽量保留已有标签、星级及材质设置。已删除文件的记录会保留并标记为失效；目录离线时，该目录的同步暂停。

复制导入与索引导入的区别在这里尤其重要。复制导入后，库内副本与外部原件是两份文件：在外部制作目录继续修改原件，不会让库内副本自动变成新版。索引目录则继续指向外部文件，因此它的可访问性依赖原目录、磁盘或网络位置。

目录同步不会把整个电脑自动纳入资源库，也不是把外部文件修改上传到云端的服务。Quick 的“监控文件夹”则是另一条收集流程：发现导出文件、等你确认后复制入库。选择功能前，先判断自己要“持续引用同一个目录”，还是“每次确认保存一份输出”。

### 17.2 查看和手动执行同步

1. 打开“设置 → 存储与资源库”，确认当前资源库名称和路径。
2. 找到“目录同步”，查看列出的“库内副本”和“索引目录”。
3. 按需要保留或关闭“自动同步目录变化”。自动同步默认开启；关闭后，可以自行选择时机手动同步。
4. 点击“立即同步”，等待扫描。扫描过程中可以继续浏览，避免连续点击同一按钮。
5. 查看已检查的文件与文件夹数量、本次新增、本次更新及标记失效数量。显示“扫描完成”后，再回列表核对变化。

同步没有新增项目，可能表示当前内容已经一致，不是没有执行。扫描中关闭软件后再打开，会重新核对并继续；不要将重新检查数量理解为所有素材都在重复复制。

若提示部分目录尚未完成，已经保存的内容会保留。先检查界面列出的不可用目录或仍在变化的目录，待磁盘接回、权限恢复或制作软件停止持续写入后，再点击“立即同步”。

### 17.3 关联早先导入的外部目录

新执行的索引目录导入会自动建立同步关联。对于早先导入、但没有出现在关联列表中的外部目录，可以在“目录同步”点击“关联已有外部索引目录”，选择原来的实际目录，完成后检查它是否出现在索引目录列表。

这个入口不会把源文件复制一份，也不负责把丢失目录的内容重新创造出来。选择前先确认文件夹确实包含你想继续引用的文件；名称相同不代表一定是原来的目录。若原文件仍在，优先恢复原盘、原目录或正确访问权限，再处理关联。

### 17.4 刷新列表和文件失效怎么处理

主界面工具栏的刷新用于重新读取当前库的可见结果并重新检查相关来源状态。想明确核对整个已关联目录的变化时，应在设置中使用“立即同步”，不要把不断刷新列表当成完成目录同步的依据。

素材变成失效或无法打开时，先检查资源库是否选对，再确认外接盘、网络位置或原文件可访问。磁盘暂时断开时，先接回并等待同步；原件确实已移到新位置时，如果详情中提供可用的“重新定位”入口，可按其核验和确认提示操作。不要为解除失效标记，把一个无关但同名的文件当作原文件。

缩略图仍然可见，不代表原件一定存在；原件能打开而缩略图空白，也不代表资源库记录丢失。先区分文件连接问题和预览问题，再决定下一步。保留失效记录，往往更有利于找回原来的标签与整理信息，不要急着删除后重新导入整个目录。

## 第18章 资源库、备份、迁移与恢复

### 18.1 管理多个资源库

进入“设置 → 存储与资源库”，可以查看当前资源库名称、路径和连接状态，并管理其他库。多个库适合分开管理不同用途的素材；切换库后，Quick、任务和维护操作都要重新核对目标。

新建或接入资源库时，展开“新建或导入资源库”，填写便于辨认的库名称，点击“浏览…”选择目录，等待软件检查目录状态，再使用确认按钮。空目录用于建立新库；发现已有库时，应按接入已有库的提示操作。目录状态未确认时，不要将它当作空目录强行新建。

已有库可从历史资源库列表切换。路径失效时，应先确认磁盘和目录是否仍在，再使用软件提供的重新关联入口。若提示“已创建，但界面连接未确认”，使用“重新连接已创建资源库”，不要反复新建同名库。关闭这个提示窗口不等于删除已经建立的库。

旧版库可能显示“升级资源库”。升级前检查备份和空间，阅读确认框后再进行。升级期间暂时停止编辑，软件会先建立可恢复材料、检查结果，再完成切换。只有出现成功并重新连接的提示，才视为可继续编辑；若显示连接仍待恢复，保留现有目录和材料，不手动替换数据库。

### 18.2 先分清两种备份范围

“设置 → 备份与维护”中的“资源库数据备份”，保存资产记录、分类、项目关联、材质和预览设置等整理数据。它不复制素材原件、外部贴图或软件配置。因此，恢复一个数据备份，可以把整理状态回到过去，却不能找回已经丢失的图片、视频或模型文件。

“本地配置与资源库复制”则复制现有配置和整个当前库目录，适合制作当前本地数据的副本。它不复制应用程序，也不会自动收集库外索引文件和外部贴图；其他历史资源库不属于“当前库”的复制范围。

准备完整备份时，需要同时考虑整理记录、库内文件和库外引用。可以先完成当前库的复制，再单独备份外部原件及模型依赖。备份最好放在不同磁盘；只在原磁盘上多保存几份，仍无法防止整块磁盘故障。

### 18.3 创建和保留数据备份

1. 确认当前连接的是需要备份的库，等待正在进行的恢复或维护结束。
2. 打开“设置 → 备份与维护”，找到“资源库数据备份”。
3. 点击“创建备份”，等待结果，不要重复点击。
4. 在“可用备份”列表查看新增条目的时间、类型、大小及验证状态；需要时点击“刷新列表”。
5. 大规模整理前，记下这个手动备份的时间，便于以后挑选恢复点。

手动备份独立保留，由你决定何时删除；自动备份轮换不会覆盖手动备份。当前自动备份保留最近 5 份，恢复前备份保留最近 2 份；恢复过程中需要的备份可能额外保留。手动备份最多保留 100 份，达到上限会停止新建，并提示先删除不再需要的手动备份，不会悄悄替你删除旧件。

界面会显示备份保存位置，它位于当前资源库中的 `.jamy_repository/backups`。这个位置方便检查容量，但日常管理应使用软件入口，不要自行改名、挪动或删除内部备份文件。

旧版库可能没有“创建备份”能力，软件会显示相应说明。这时可以使用“选择复制位置”保存当前库数据；对于列表中已经验证且允许恢复的旧备份，按界面提供的恢复步骤处理。不要因为按钮缺失，就从别的资源库手工拷贝一份备份文件进来。

### 18.4 删除不再需要的手动备份

在“可用备份”中找到明确标记为手动备份的条目，核对时间后点击该条目的“删除”。确认框会说明：删除的只是这个恢复点，当前资源库和素材文件不受影响，删除后无法恢复。确定不再需要时再确认。

删除完成后检查列表，必要时刷新，再创建新备份。自动备份和恢复过程中受保护的备份不提供同样的删除入口；恢复正在进行时，删除按钮也可能暂时不可用。不要通过手动删内部文件绕过这些限制。

为了保留有价值的节点，可以把大规模分类、批量修改或迁移之前的手动备份留下，将用途相同、确认不再需要的旧恢复点清理掉。清理前先确认另外保存的完整素材备份仍可用。

### 18.5 恢复整理记录

恢复适合撤回较大范围的整理变化，不适合解决原件已经丢失的问题。操作前先判断：需要回退的是标签、分类、材质设置等记录，还是需要从另一个磁盘找回文件本身。

1. 切换到准备恢复的资源库，暂停继续整理。
2. 进入“设置 → 备份与维护 → 可用备份”，按时间选择恢复点。
3. 点击“恢复此备份”，等待软件核验，再仔细阅读确认框。
4. 确认框会说明当前库记录将被替换，备份之后的编辑可能回退。确认接受这个结果后继续；不确定时取消，不会开始正式恢复。
5. 等待“备份已恢复，资源库已连接”，再核对标签、分类和几个代表性素材。

恢复前软件会保留当前数据库的备份，但这仍不是素材文件备份。恢复完成后，当前新库流程无需重启；旧版库的恢复可能重新加载界面，应以其实际提示为准。

如果出现“数据已恢复，但资源库连接尚未完成”，编辑会继续暂停。先查看维护状态、刷新备份列表，并在提供时使用“继续恢复”。若只得到“结果未确认”，不要立刻另选一个备份再次提交，更不要用旧数据库手工覆盖当前文件。保留现场，按提示恢复连接；需要求助时记录版本、选中的恢复点和原始错误提示。

### 18.6 复制当前配置和资源库

1. 在主界面核对要复制的当前库，并确认目标磁盘有足够空间。
2. 进入“设置 → 备份与维护 → 本地配置与资源库复制”。
3. 点击“选择复制位置”，选择独立的目标目录，不要放在正在复制的资源库内部。
4. 软件会在该位置新建 `jamy-data`。如果目标已存在同名目录，会拒绝覆盖或合并，改选另一个位置即可。
5. 复制期间保持当前库和目标磁盘可用，等待明确的完成提示。
6. 完成后保留源库，检查副本及外部素材的备份情况，再安排后续迁移。

复制期间资源库会暂时停止写入；若提示正在备份或维护，等待原操作完成后重试。目标中出现 `jamy-data` 不等于复制已经成功，尤其不能把“复制未完成”“收尾未确认”的目录直接当作可靠副本。

这项功能没有复制 JAMY 应用，也不保证把生成目录放到另一台电脑就能直接运行。换电脑时仍需安装适合该系统的版本，核对资源库连接和外部路径。涉及 API、外部程序、本地模型等设置时，也应逐项检查新电脑上的实际可用性，不要只看原设置文字还在就认为环境已经完整迁移。

### 18.7 迁移后的检查与保留

迁移或换盘后，先用小范围核对结果：检查库名称和路径、分类与标签、几张图片、一个带贴图模型，以及一个外部索引文件。关闭后再打开 JAMY，确认仍连接正确的库，代表性素材仍能访问。

外链文件无法打开时，先恢复对应磁盘、目录或权限；复制当前库并不会自动改写所有外部原件的路径。确认整个使用流程稳定之前，保留旧库和完整素材备份，不要把清空源目录当作迁移步骤的一部分。

“仅解除关联”、删除素材和移除整个资源库具有不同范围。日常维护不需要删除库来修复缩略图，也不应通过清空数据库来解决短暂断联。遇到结果不明的库操作，停止重复提交、保留目录并记录提示，比不断重试破坏性操作更容易查清问题。

## 第19章 设置、性能与任务中心

### 19.1 找到需要的设置

点击侧栏“设置”，左侧可见“常规”“存储与资源库”“导入与快捷窗口”“预览”“AI 分析与搜索”“备份与维护”和“关于软件”。窗口较窄时，分类可能横向排列，当前页的内容也可能需要向下滚动。

日常外观放在“常规”；资源库连接和目录同步在“存储与资源库”；Quick、文件夹监控和手机传输在“导入与快捷窗口”；3D 默认行为在“预览”；模型准备及 AI 队列按“AI 分析与搜索”的专门流程配置；备份、恢复和日志在“备份与维护”。不要把普通外观设置与维护操作混在一起批量调整，便于知道哪一步带来了变化。

### 19.2 主题、语言与素材显示

“常规”提供极简白、柔和绿、暖咖啡、暗夜红和赛博蓝等主题，点击主题卡片查看效果；语言可选简体中文或 English。切换界面语言不会把你的文件名、标签或素材内容自动翻译成另一种语言。

素材显示方式在主界面工具栏调整，而不在主题卡片中。点击相应图标选择“对齐网格”“瀑布流”或“详细列表”。对齐网格便于整齐比较，瀑布流按素材比例展示，详细列表便于查看文字信息。切换布局只改变浏览方式，不会重新复制素材。

非列表布局可以选择五档缩略图尺寸。较窄窗口可能把五个按钮合为一个尺寸按钮，连续点击即可切换。打开“显示选项”，可以调整透明图片背景；“瀑布流隐藏资产名称”只在瀑布流布局中可用。需要辨认透明素材边缘时，先换合适的背景，不必为了看清楚而修改原图片。

### 19.3 排序与筛选后的结果

点击工具栏“排序”，按加入时间、名称或大小选择升序、降序。当前范围包含相应媒体时，还会显示图片或视频分辨率、视频时长、模型三角面数等排序项。某些数据尚未提取或类型不适用时，不能凭排序位置推断文件本身损坏。

整理后觉得“素材变少”或“顺序不对”，先检查当前目录、搜索词、高级筛选及排序选择。清空不需要的条件，再刷新查看。AI 语义搜索有自己的相关度结果，不应拿普通名称排序的位置判断语义结果是否正确；需要恢复普通浏览时，退出相应搜索状态再检查。

### 19.4 根据电脑负载调整使用方式

普通电脑可先减少同时进行的重任务：批量导入时先等待收录，随后再做大批 AI 分析；预览较重模型时，暂时关闭不需要的其他大型程序。不要因为任务等待就连续增加同类任务，这会使结果更难判断。

在“设置 → 预览”可以调整小窗口自动旋转、锁定跟随物体和地面网格等默认行为。大窗口默认不自动旋转，可在预览中手动开启。动画播放／暂停快捷键默认为空格，也可改成 K、P 或关闭。这里的“单击导航行为”控制进入文件夹，不改变素材的选择和预览方式。

模型加载耗时同时受模型结构、贴图和设备影响，磁盘文件大小不等于实际内存或显存占用。显示需要确认或超过预览范围时，按预览提示处理；手动确认也不会取消安全限制。关闭不需要的预览后再尝试其他文件，通常比反复点击同一个大模型更容易确认问题。

本地 AI 需要相应模型和可用内存。等待可用内存、等待 AI 空闲或等待模型服务，不代表素材已经分析失败。先查看 AI 页面给出的具体原因，释放资源后让原任务继续或按提供的按钮恢复。不要为了“提速”删除模型、缓存或资源库中的文件。

### 19.5 用任务中心判断正在发生什么

主界面底部的“任务”会汇总进行中、等待或需要处理的工作。点击展开“资产任务”，再展开具体任务，查看说明和可用操作。

“进行中”表示工作仍在运行，可观察阶段、数量和提示；“等待”表示暂时缺少资源或条件，应按原因处理；“需处理”通常有错误、待确认结果或需要你继续的步骤，应先展开阅读；短暂出现的“已完成”提示表示有任务完成，不代表所有素材和所有后台工作都已全部处理。

目录同步、手机待入库以及其他维护或派生处理可能在这里显示。Quick 的“最近收录”和主界面的“AI 分析任务”还有各自更详细的记录：查看问题时选择与任务来源对应的入口。关闭任务面板只是收起信息，不会自动取消任务。

当提示结果待确认，先使用“核验”“刷新结果”或“继续”等当前界面实际提供的入口。只有明确提供取消操作时，才按说明取消；取消未完成部分并不保证撤销已经保存的内容。等待和部分完成都不应直接当作整批失败重做。

### 19.6 缩略图、预览与诊断

缩略图空白时，先选中素材，确认原文件是否存在、能否打开，再判断是否为格式不支持、预览仍在排队或文件超出安全范围。当前版本没有适用于全部资源库和格式的通用“修复所有缩略图”入口，不能把刷新等同于重新生成所有预览。

部分旧版库可能显示“全局断链检测”或“清理孤儿缩略图”等维护项；这些入口受资源库类型与状态限制。清理孤儿缩略图用于清理不再被记录引用的缓存，不会修复缺失的源文件。新库没有同样按钮时，不必寻找内部目录手工清空。

问题持续存在时，到“设置 → 关于软件”记下版本与构建信息，再在“备份与维护”按需要导出诊断日志。导出只把文件保存在本机，不会自动发送。提交反馈前写清操作步骤、预期结果、实际提示和涉及的文件类型，并检查日志、路径和截图是否包含私人或保密内容。

清理日志不是修复功能。排查期间先保留相关日志和原始错误提示，避免一边求助一边把证据清掉。对于库连接、恢复或收录结果未确认的问题，保留原数据并停止重复提交，是后续准确判断状态的重要前提。

## 第20章 玩法1 建立能反复找到参考图的素材库

**适合谁**：经常保存图片，却只能凭文件名和记忆翻找的用户。

**最终成果**：一组有分类、人工标签和可信 AI 描述的参考图，既能按明确条件找，也能用自然语言寻找相近内容。

### 20.1 先准备一个小样本

选择20张左右的静态 JPG、PNG 或 WebP 图片，尽量包含不同主题和构图。先不要对全库启动分析。

1. 新建“参考图”分类，将图片导入其中。
2. 为已经知道用途的图片添加“角色”“场景”“构图”等人工标签。
3. 给最值得保留的图片评四星或五星。
4. 用普通搜索验证这些人工标签能找到对应图片。

这一轮先建立可靠的基础信息，之后可以用同一组素材判断 AI 是否真的有帮助。

### 20.2 补充 AI 分析

按[第13章](#chapter-13)完成本地或自定义 API 配置，并分别确认图片分析与搜索能力。

1. 在“参考图”中选中少量支持的图片，启动图片分析。
2. 到任务中心查看结果，区分等待、完成、失败与跳过。
3. 回到详情，逐张检查描述和 AI 标签。
4. 纠正明显错误，特别是主体、颜色、数量和场景关系；不要仅因文字流畅就接受。
5. 再按[第14章](#chapter-14)准备 AI 搜索需要的索引。

分析和搜索准备是两个环节。图片有分析结果，不代表所有搜索准备都已完成。

### 20.3 设计三种查找练习

**确定名字时**：用普通搜索查文件名或明确标签，例如“场景”。

**确定特征时**：结合颜色、横竖比例和评分筛选，例如“暖色横图、四星及以上”。

**只记得大致内容时**：尝试 AI 搜索，例如“雨夜街道上的人物背影”。结果出现后，仍要打开图片确认。

选三张你已经看过的图片，分别用这三种方法找回。记录哪种方法最省时间，而不是只追求 AI 返回更多结果。

### 20.4 形成日常整理习惯

每次收集完一批图片，先归类，再挑重点，最后才决定哪些需要 AI 分析。对明显不会再用的临时图片，不必承担整批分析的等待和 API 成本。

“已用于第一稿”“客户认可”等信息由你添加人工标签；AI 可以描述画面，但无法替你知道项目决策。

**完成判断**：隔一天后，不依赖原文件夹顺序，也能用标签、筛选或自然语言找到几张指定图片。

**容易遇到的问题**：搜索结果偏差大时，先检查图片描述是否正确，再检查索引是否准备好。查询中的“黄色”等特征不准，可以结合色彩筛选；不要不停重跑全部分析。

## 第21章 玩法2 用组合筛选建立动态选片习惯

**适合谁**：素材已经不少，想迅速找出重点候选、新收录内容或特定尺寸图片的用户。

**最终成果**：几组自己熟悉的筛选组合。它们会按当前素材信息匹配结果，但本版没有把条件保存为智能文件夹的入口；再次使用时按需要设置条件。

### 21.1 组合一 找出四星及以上的参考图

1. 进入“全部资产”，清空搜索并重置已有筛选。
2. 将类型范围切为图片。
3. 点击顶部“高级筛选”，再打开“星级”。
4. 在底部星星中点击第四颗，条件显示为“4星+”。
5. 浏览结果，挑出本次真正需要的图片，加入已建好的项目。

四星条件表示四星及以上，不是只显示四星。评分改变后，素材是否符合当前条件也会变化。

### 21.2 组合二 找最近收录的模型

1. 先重置上一组筛选。
2. 切换到模型类型。
3. 打开“高级筛选”，在时间条件中选择“最近 7 天”。
4. 逐个预览近期素材，给值得继续评估的内容加上“待试用”标签。
5. 要查固定日期范围时，改用自定义时间并填写起止日期。

时间筛选关注收录时间，不能当作模型实际制作时间。界面“本月”对应最近30天；按自然月检查时请使用自定义时间。

### 21.3 组合三 找适合横屏画面的高分辨率图片

1. 回到图片范围并清除不需要的时间、星级条件。
2. 打开“高级筛选”，在比例中选择16:9；使用自定义比例时，填写比例与容差后点击“应用比例”。
3. 在分辨率中选择合适的长边像素范围。
4. 如有配色要求，追加色彩条件。
5. 打开结果检查主体位置、留白和实际清晰度，再加入项目。

像素范围按已知长边尺寸匹配，不能直接理解为“画质足够好”。比例也不表示已经完成裁切；后续构图处理仍在创作工具中完成。

### 21.4 结果太少时怎样放宽

依次撤去最苛刻的一项：先放宽颜色容差，再放宽比例或尺寸，最后考虑降低星级。一次只改一个条件，更容易看出是什么在排除素材。

未知尺寸或尚无色板的素材，可能还不能按这些属性完整匹配。先让相关信息准备完成，再判断是否确实没有合适内容。

**完成判断**：你能解释每一项筛选在缩小什么范围，也能清空条件回到完整视图。

**整理建议**：需要长期保留本次选片结果时，将选中的素材加入项目，或逐项添加同一个人工标签。这样保留的是选定的素材关系，不是假设已经保存了筛选规则。

<a id="chapter-22"></a>
## 第22章 玩法3 为一个 AI 短片建立素材工作台

**适合谁**：使用外部 AI 工具生成画面、视频和声音，希望统一管理参考、提示词、候选版本与最终选片的创作者。

**最终成果**：一个按场景和镜头组织的短片项目。每个镜头能找到参考图、候选画面、视频、声音和对应提示词。

本例使用虚构短片“雾城来信”：角色在雨夜进入街角，发现一封信，抬头看向远处。JAMY 负责组织与取用素材；画面生成和视频剪辑在你选择的外部工具中完成。

### 22.1 先确定简单命名规则

用一套简短编号贯穿文件、标签和外部工程：

- 项目：雾城来信。
- 场景：S01 雨夜街角。
- 镜头：SH001 进入街道、SH002 发现信件、SH003 抬头。
- 版本：v01、v02、v03。
- 状态标签：候选、已选、待重做。

这些名称是工作方法，不是 JAMY 强制格式。第一部短片可以只做三个镜头，避免先搭建复杂空结构。

### 22.2 创建项目与镜头层级

1. 点击左侧“项目”，必要时展开项目导航。
2. 在“全部项目”层点击“＋ 新建项目”，名称输入“雾城来信”，点击“新建项目”。
3. 点击新建的项目进入，点击“＋ 新建下级”，名称填“第一段”，在“层级（可跳过）”中选“章节”，点击“新建章节”。
4. 保存后仍在父级列表。点击“第一段”进入，再点击“＋ 新建下级”，选择“场景”，名称填“S01 雨夜街角”，点击“新建场景”。
5. 点击该场景进入，再新建下级，在层级中选“镜头”，填写“SH001 进入街道”，点击“新建镜头”。
6. 留在场景的下级列表，重复新建操作，建立SH002和SH003。查看某镜头后，可点导航路径返回场景层。

项目支持项目、章节、场景、镜头等层级。按你的实际结构选择；镜头层用于承接具体素材，不需要继续往下建层级。

**完成判断**：能够通过项目导航分别进入三个镜头，并清楚知道自己当前在哪一级。

### 22.3 先把参考资料放到正确位置

先将角色参考图、街景、灯光氛围和信件道具图导入资产库，再建立项目关联。

1. 回到“资产库”，重新选择需要的参考图。切换页面会清空选择，需重新选中。
2. 点击底部“加入项目”。
3. 在弹窗中选择已经建好的项目、场景或具体镜头，核对“加入到”的名称。
4. 展开“设置用途（可选）”，选择“参考”。
5. 点击“加入项目”确认，随后进入目标位置查看结果。

通用角色设定可以放在项目或场景级；只有某镜头需要的构图参考放在对应镜头。父级资料不会自动在子镜头里显示，需要返回父级查看，或把同一素材另行加入对应镜头。若多个镜头都需要同一素材，可以分别建立关联，不必因此重新复制导入。

加入项目弹窗用于选择已有位置，不能在里面临时新建完整项目。先建结构，再选素材，会更顺畅。

### 22.4 保存提示词和生成说明

在外部文本编辑器中准备提示词文件，例如 `S01_SH001_提示词_v01.txt`。内容可以包含：

- 本镜头要发生什么。
- 人物、场景与构图要求。
- 使用的外部工具及模型名称。
- 实际提交的提示词与需要保留的参数。
- 对应参考图和生成结果的文件名。

然后按以下步骤收录：

1. 保存文本文件，将它导入 JAMY。
2. 选中文本，点击“加入项目”，选择SH001。
3. 将本次新增用途设为“提示词”，确认加入。
4. 进入SH001，按“提示词”用途查找，确认能找到该文件。

“提示词”是项目中的用途分类，不会自动把文字提交给生成模型。API 密钥、账号密码不应写进素材文件。

### 22.5 收录候选画面与视频

1. 在外部工具生成候选图片或视频，并保存到本地。
2. 使用包含镜头号和版本号的文件名，例如 `S01_SH001_画面_v02.png`。
3. 导入 JAMY，加入对应镜头，按实际用途选择“图片”或“视频”。
4. 给尚未决定的内容加“候选”标签。
5. 逐张、逐段预览，挑出更合适的版本，设置较高评分。

使用包含版本号的独立文件，能够保留选择过程。若只改 JAMY 显示名称，磁盘文件名不会因此同步改变；不能靠显示名代替外部工程的版本管理。

### 22.6 区分已选与待重做

选择版本时，既看单个画面，也检查相邻镜头中的人物外观、道具、光线和动作方向。

1. 对确定使用的素材添加“已选”标签，按约定设置五星。
2. 对需要再生成的内容添加“待重做”，避免混进最终选片。
3. 去掉已经不适用的旧状态标签，避免同时保留“候选”和“已选”导致理解混乱。
4. 更新对应提示词文件或保存新版本，先导入资产库，再通过“加入项目”关联到该镜头。

这些状态由你维护。JAMY 不会自动判断哪个版本已经被剪辑工程采用，也不会自动保证角色一致性。

### 22.7 放入声音与剪辑素材

将对白、环境声、音乐分别导入，并加入场景或镜头，设置“音频”用途。给素材添加“雨声”“脚步”“对白”等人工标签，有助于后续选择。

准备剪辑时：

1. 进入对应镜头，查找已经选定的图片、视频和声音。
2. 预览并核对版本。
3. 按第08章导出或定位后复制到外部剪辑项目目录。
4. 在剪辑软件中导入文件，完成剪辑、混音和输出。
5. 将需要留存的成片或修订版本重新收录到 JAMY。

项目视图不是剪辑时间线，也不会替外部工程自动收集所有依赖。交付前仍需在剪辑工具中确认素材链接和输出。

### 22.8 检查工作台是否真的可用

随机进入一个镜头，尝试回答：参考是什么、提示词在哪、有哪些版本、当前选哪个、对应声音是什么、能否找到磁盘文件。

如果这些问题能在短时间内回答，工作台就发挥了作用。

**常见问题**：素材加错镜头时，移出错误关联，再加入正确镜头；不要为了改归属删除素材本身。用途只是帮助查找，暂时不确定时可以先不指定，后面再补。需要给别人交付时，不要只发送项目名称或 JAMY 记录备份，应另行整理实际文件。

<a id="chapter-23"></a>
## 第23章 玩法4 建立便于挑选的模型与材质展示库

**适合谁**：有一批模型，希望不用每次启动 DCC 就能判断外形、贴图效果和是否值得进一步使用的用户。

**最终成果**：模型有清楚的分类、可辨认的预览和封面，材质依赖得到检查，挑选之后能够在创作工具继续工作。

### 23.1 先做三个代表性样本

选择一个简单静态模型、一个带多个材质的模型，以及一个带外部贴图的模型。按第03章导入，先检查这些代表性情况，再批量收录。

不要仅凭扩展名判断可用性。文件损坏、依赖丢失或体积与复杂度超出当前预览范围，都可能使同一种格式表现不同。

### 23.2 统一观察方法

1. 单击模型，在右侧查看3D预览。
2. 点击“大预览”，获得更大的应用内观察空间。
3. 旋转查看主要方向，调整缩放，确认主体没有被裁掉。
4. 切换线框或其他显示方式，查看轮廓与结构。
5. 调整光照或选择支持的 HDRI 环境，观察材质反应。

为了方便比较，尽量让同类模型使用接近的视角、光照和背景。好看的封面有助于挑选，但不应掩盖缺件或错误贴图。

### 23.3 检查材质和依赖

按第10章进入材质设置，区分全局调整与指定材质槽。逐个检查颜色贴图、法线等实际使用的通道，避免把同一张图放错位置。

新增贴图后查看效果，等待材质自动保存并确认状态。若模型白模、全黑或某个部位明显异常，先核对贴图文件是否可读、是否放对材质和通道，再调整光照。

这里设置的是 JAMY 预览中的效果。之后进入 Blender、Maya 或其他创作工具时，仍需按目标工具检查材质，不能假设库内预览设置已写回原模型。

### 23.4 生成辨认度高的封面

1. 把模型调整到能看清主体的角度和大小。
2. 等待预览设置自动保存，确认显示已保存。
3. 点击相机图标对应的“提取缩略图”或“渲染提取缩略图”。
4. 等待保存成功，回到素材列表查看封面。
5. 再次打开模型，核对保存后的效果。

封面应能区分“这是哪一个模型”，不必为每个文件追求宣传图级渲染。静态回退或受限状态不能保证可以更新缩略图，应按界面提示处理。

### 23.5 形成可复用的标签

可用“建筑”“道具”“角色”等类别，加上“已检查贴图”“待修材质”“优先使用”等状态。面数、可商用范围等信息必须依据实际模型与授权资料，不凭外观或 AI 猜测。

**完成判断**：只看列表和预览，就能选出候选；定位文件后，在外部创作工具中能确认模型和必要贴图。

**常见问题**：JAMY 里的预览正常，外部工具仍可能缺材质，因为两边的材质系统和设置不同。当前不能把这个流程描述为 Blender 插件一键双向同步，也不应声称能直接实时预览所有 `.blend`、`.max` 或 `.ma` 工程。

<a id="chapter-24"></a>
## 第24章 玩法5 建立动作参考与关键姿态库

**适合谁**：需要挑选角色动作、观察骨骼运动，或记录某个动作中关键姿态的用户。

**最终成果**：能够预览的动作素材、清楚的分类和标签，以及与原模型兼容的已保存姿态。

### 24.1 导入并检查动作文件

先选一个已知带动画或骨骼的文件，按第11章检查是否能进入动态预览。格式支持不等于每个文件都一定带动画。

1. 单击素材进入预览，等待读取结束。
2. 打开动画控制，确认是否有可选择的动画片段。
3. 播放、暂停，并拖动进度，查看动作的主要阶段。
4. 适当调整播放速度，观察接触地面、重心和手脚关系。
5. 添加“走路”“起身”“跳跃”等人工标签，标记用途。

### 24.2 用骨骼显示观察运动

对支持的骨骼预览，切换完整与简化显示，检查动作整体方向。

简化显示主要隐藏已识别的辅助骨骼和手指细节，帮助看清主体动作。它不会精简源文件中的骨骼，也不会改变动画数据；未识别的骨骼仍可能保留。

动作朝向或姿态看起来异常时，可先换一个已知正常样本比较，再到源工具核对文件；不要把显示开关当作数据修复工具。

### 24.3 保存一个关键姿态

1. 暂停在要记录的时刻，必要时调整进度到合适位置。
2. 打开“姿态/混合”。
3. 在“姿态名称”中输入“起跳前蹲伏”等有含义的名称。
4. 点击“保存当前姿态”，等待成功。
5. 播放到其他位置，再打开姿态面板，对刚才的姿态点击“应用”。
6. 需要继续播放时，点击“返回单动画”。

同名姿态会出现覆盖确认，确认前先想清楚是否要替换原记录。来源或骨架变化后，旧姿态可能不兼容；“重建姿态库”会删除旧姿态，不是无损刷新。

### 24.4 试用同骨架动画混合

只有当前模型中存在足够的兼容片段时，才会出现相应的混合选择。

1. 先选一个主动画，保持在动画模式。
2. 在“姿态/混合”中找到“同骨架动画混合”。
3. 选择第二个兼容动画。
4. 调整“混合权重”，观察不同占比的效果。
5. 对照完成后选择“单动画”，恢复普通播放。

本功能用于同一模型中兼容动画的预览，不是给任意两个角色重定向，也不会自动生成可交付的新 FBX 动作。

### 24.5 让动作库服务实际创作

把已选动作加入项目，设置“动作”用途。需要制作时定位源文件，在 DCC 或引擎中完成重定向、修脚滑、曲线编辑和导出。

**完成判断**：能找到一种指定动作、播放检查、保存并重新应用一个姿态，还能定位到真正的源文件。

**常见问题**：无动画列表时，先核对文件本身；提示超出安全预览范围时，保留文件，可在原工具制作更轻的预览版本。不能把“保存姿态”理解为生成独立骨骼资产或自动导出动画。

<a id="chapter-25"></a>
## 第25章 玩法6 从快速收集到定期归档

**适合谁**：浏览网页、查看文件时经常发现素材，但不想当场完成所有分类的用户。

**最终成果**：收集入口统一、未整理素材容易找到，每周能完成一次有结果的归档。

### 25.1 设置一个收集入口

按第15章找回 Quick，选择本次目标库和分类。建议先准备“待整理”文件夹；也可以使用收件箱入口管理尚未归档的内容，注意以实际导入结果确认位置。

1. 将少量本地文件拖入 Quick，先检查待导入列表。
2. 选择目标，按需要填写本次标签，例如“待整理”。
3. 确认导入，等待成功后再继续下一批。
4. 在主窗口找到这批素材，验证确实已经入库。

Quick 的本地收集使用 Copy，不等于主窗口可选择的 Link 导入。批次有数量限制，大批目录应走主窗口的相应导入流程。

### 25.2 网页收集保留来源意识

使用网页图片时，先确认有权下载和使用。可拖入的图片也可能因站点限制、防盗链或实际地址无效而失败；拖拽并不保证获得原始最高分辨率文件。

能下载不等于可商用。需要保留授权说明时，把对应许可文本或来源记录另存为素材并归入项目，不能仅凭文件已进入 JAMY 判断授权。

### 25.3 需要监控时先做小范围试用

按第15章添加一个专用的收集目录，使用普通文件试验“发现—待确认—导入”。不要直接将整个系统下载盘当作无条件自动入库来源。

Quick 监控与目录同步有不同目标：前者帮助发现待收集文件，后者维护已登记目录与库记录之间的变化。监控发现不等于已入库，仍需核对确认步骤。

### 25.4 每周做一次有边界的整理

1. 打开“待整理”或收件箱，清除无关搜索条件。
2. 逐批查看内容，给值得保留的素材分类。
3. 补充内容标签和评分。
4. 已有具体用途的加入项目。
5. 去掉“待整理”等已完成状态标签。
6. 对不再保留的条目，按第08章先理解删除选项，再操作。

一次只整理一个可完成的小批次。整理后能检索和取用，比把所有条目暂时挪进同一个目录更有用。

**完成判断**：新收集素材有明确入口，整理后的素材能从分类或项目找到，待整理范围逐步缩小。

**常见问题**：重启 JAMY 或切换资源库后，文件夹监控会暂停，需要在设置中重新确认原目录并恢复。收集后没看到时先查收录结果，不要只因浮窗收起就认为导入成功。

<a id="chapter-26"></a>
## 第26章 玩法7 从参考图提取配色并寻找同色素材

**适合谁**：需要为短片、场景或视觉设计建立配色参考的用户。

**最终成果**：几张可靠参考图的色板、可复制的色值，以及通过色彩筛选找到的候选素材。

### 26.1 选择适合提取的参考图

先选主体明确、整体配色接近目标的图片。若画面中有大面积边框、截图界面或水印，它们也可能影响统计出的颜色。

1. 单击图片，找到右侧“智能色板”。
2. 点击“提取色板”；已有色板但需要重新计算时用“重新提取”。
3. 等待成功，观察颜色和比例。
4. 对照原图，判断这些颜色是否代表你想使用的主体。

色板反映图像中提取出的颜色分布，不代表作品经过专业配色判断，也不一定只来自主体。

### 26.2 把色值带到创作工具

点击具体色块或色值，将 HEX 颜色复制到剪贴板；在支持 HEX 输入的绘图、设计或其他工具中粘贴。

需要一组网页颜色变量时，可以使用色板区的“CSS”，再粘贴到自己的样式文件或交付文档中。

本流程以 HEX 和 CSS 为准。需要专业色板文件时，应在目标工具中验证兼容性，不把文件扩展名当作一定兼容的保证。

### 26.3 用同一色调寻找其他素材

1. 进入“全部资产”并选择图片范围。
2. 打开筛选区的“色彩/色轮”。
3. 选择预设颜色，或输入完整有效的六位 HEX 色值，例如 `#336699`，输入有效后会自动生效。
4. 从较窄的容差开始，查看结果。
5. 结果太少时逐渐放宽容差，再结合比例、评分等条件。
6. 打开候选图检查，把符合本项目配色的素材加入项目。

色彩筛选依据已提取色板，未完成色板准备的素材可能暂时匹配不到。某种颜色占比很小的图片，也不能因为能匹配就认定整体配色一致。

### 26.4 建立项目配色参考

选择一到三张最能代表项目色调的图片，加入项目并设置“参考”用途，添加“主色参考”标签。其他候选图可标为“配色候选”。

对 AI 短片，可以把这组资料放在场景层，供各镜头选片时对照。需要一张自由排布的拼贴板时，在外部设计工具制作，再把输出收录回来；本流程不依赖 JAMY 内置无限画布。

**完成判断**：你能复制一个色值用于实际工具，也能从库中找到几张配色接近的候选，并判断哪些只是局部颜色相近。

**常见问题**：纯黑、透明背景或画面边缘占比较大时，要回到原图解释色板结果。显示器与目标工具的色彩管理也可能影响观感，色板不能代替最终输出检查。

<a id="chapter-27"></a>
## 第27章 玩法8 管理大型素材硬盘

**适合谁**：已有大规模图片、模型或声音目录，希望减少重复复制，同时保留可查找的资料库的用户。

**最终成果**：清楚的原文件位置、可检查的目录同步关系，以及彼此独立的整理记录与素材备份。

### 27.1 先规划存储再导入

将经常使用且位置稳定的素材目录作为 Link 候选。临时下载、经常清理或来自尚未整理 U 盘的文件，可以先确定长期位置，或使用 Copy。

先记录两类位置：JAMY 资源库目录，以及库外被引用的素材目录。后续备份和迁移必须同时考虑它们。

### 27.2 用一个子目录验证 Link

1. 先选择数量有限、结构清楚的子目录。
2. 在主窗口使用本地导入入口，选择 Link，并阅读目录扫描与确认信息。
3. 等待完成，检查成功、跳过和失败的结果。
4. 随机打开几张图片、一个模型或一段音频，确认文件可读。
5. 在目录同步区域核对被登记的外部目录和当前状态。

验证后再按目录分批扩大范围。不要为了“全部加入”绕过数量、体积或预览限制。

### 27.3 理解文件变化怎样影响素材库

已登记目录发生新增、修改、改名或移动时，目录同步会按自身范围处理变化；具体检查方式见第17章。

外置硬盘离线时先重新连接并核对盘符、路径和权限，不要把暂时不可访问的全部条目删除。源文件被删除后，库中记录不能凭空重建内容。

Copy 的外部原始目录与库内副本是不同位置，不能假设修改原文件会自动更新副本。

### 27.4 建立两层备份

**第一层是整理记录。** 当前库支持且允许创建时，重大批量整理前先完成手动备份，并确认成功。按钮不可用时，按第18章的旧版库或恢复说明处理，不要反复提交。

**第二层是实际文件。** 另行备份资源库中的托管文件，以及 Link 引用的外部素材目录。重要资料建议存到另一物理磁盘，避免一个磁盘故障同时损失原件与备份。

手动记录备份有数量上限，并且不会随自动备份轮换自动清掉。接近上限时先确认保留方案，再清理明确不需要的手动记录备份。

### 27.5 迁移前后怎样核对

1. 等待导入和其他写入任务结束。
2. 按第18章确认可用的记录备份，并另行保护实际素材文件。
3. 按第18章执行资源库相关复制或迁移。
4. 对库外引用单独安排文件复制和路径核对。
5. 在目标位置检查分类、标签、项目、图片、模型依赖和外部链接。
6. 关闭并重新打开，再检查几个代表性样本。

目标验证完成前保留原位置。软件中的“本地配置与资源库复制”不包含所有外部 Link 文件，也不应理解为任意电脑间零配置迁移。

**完成判断**：你知道每类文件在哪、离线会影响什么、记录怎么恢复、实际文件从哪恢复。库能打开只是检查的一部分，还要实际预览和定位样本。

**常见问题**：记录恢复成功但文件仍丢失，说明还需要恢复原文件；目录同步不是备份，不能替你保留已删除内容的历史版本。

<a id="chapter-28"></a>
## 第28章 常见问题与排查顺序

**本章目标**：先判断问题属于显示、筛选、文件、任务还是资源库，再选择范围最小的处理方法。

### 28.1 先记下这五件事

需要排查时，先记录软件版本、当前资源库、刚才的操作、完整提示和大致发生时间。再判断是一个素材有问题，还是很多不同素材同时有问题。

一个模型失败，通常先查该模型；全部文件突然不可访问，先查磁盘、库连接与权限。不要把这两种情况都用重新导入整库处理。

### 28.2 素材突然不见了

1. 确认当前资源库名称和路径。
2. 回到“全部资产”。
3. 清空搜索，重置类型、评分、时间、标签和颜色等条件。
4. 退出 AI 搜索，回到关键词或普通浏览。
5. 查看任务结果，确认之前导入是否成功、是否作为重复处理、是否加入了其他分类。

如果记录找到了但提示文件缺失，转到下一节。找不到记录时不要先移动磁盘目录，以免增加第二个问题。

### 28.3 有卡片和封面，但文件打不开

1. 选中素材，在详情查看其来源与路径。
2. 使用“在文件资源管理器中定位”，检查文件是否存在。
3. Link 素材需要检查原磁盘是否在线、路径是否变化、是否有访问权限。
4. 目录已登记同步时，查看同步状态；离线先恢复连接。
5. 文件确实删除时，从自己的文件备份恢复，再核对对应记录。

封面是浏览信息，不是原文件的完整备份。恢复数据库记录也不能还原已经丢失的图片、模型或贴图。

### 28.4 导入数量与选择数量不一致

查看结果中的成功、重复、跳过、失败或待核验项。文件格式、目录扫描规则、当前文件状态和已有记录都会影响实际收录数量。

对确定失败的文件检查原因后再重试；结果待核验时先查看原任务，不要反复新建同一批导入。目录导入还应确认是否已经完成“目录复制确认”等步骤。

怀疑被错误判断为重复时，保留两个待比较的原文件及结果提示，使用非保密样本反馈。不需要为验证重复而清空整个资源库。

### 28.5 缩略图空白 模糊或不更新

先区分三件事：列表缩略图、详情预览、实际文件。原文件能打开、只有卡片异常时，重点检查缩略图任务；详情也失败时继续检查格式、资源和文件状态。

1. 等待当前任务，查看是否正在为前台浏览让路或等待内存。
2. 选中素材查看具体原因。
3. 模型支持时可手动提取缩略图。
4. 具备“核验并修复缩略图”入口的图片，可阅读说明后执行；该能力有格式、来源和核验条件限制。
5. 仍异常时导出日志并附具体素材类型与提示。

没有一个对全部格式都适用的通用修复按钮。不要删除内部数据库、缓存目录或原素材来强行刷新。

### 28.6 模型白模 全黑或加载慢

白模先查贴图依赖、材质槽和通道；全黑同时检查光照、环境与材质设置；方向异常先核对文件在原制作软件中的表现。

加载慢时查看是否超出预览范围或正在等待资源。模型文件体积很小，也可能有复杂骨骼、大量采样或外部贴图。先用已知正常的小模型比较，再选择是否在原工具导出轻量副本。

JAMY 预览效果不必与原制作软件完全相同。重建材质和精修动作应在对应创作工具中完成。

### 28.7 动作没播放 或姿态不能应用

先确认当前文件含可读取动画，打开动画控制检查是否暂停、是否有片段可选、是否处于静态预览。静态预览不能播放动画。

姿态依赖兼容的来源与骨架。源文件变化后，旧姿态可能失效；重建姿态库会删除旧记录，不能把它当作无损修复。保存结果待核验时先核对原操作，不要连续覆盖。

### 28.8 AI 配置看起来填好了 却不能分析

先检查是否“应用 AI 设置”，再分别执行图片分析和搜索检查。模型名存在、服务可连接与实际能力通过，是不同状态。

本地来源需要组件、模型和可用资源；自定义 API 需要正确的基础地址、密钥、权限与兼容模型。不要把网页聊天地址填进 Base URL。

当前图片分析范围是静态 PNG、JPEG、WebP。一个模型文件能被 JAMY 预览，不代表它能进入图片 AI 分析。

### 28.9 AI 搜索找不到明明存在的图片

1. 先用文件名或人工标签普通搜索，确认素材存在。
2. 检查 AI 描述是否包含真正可见的内容。
3. 检查搜索准备是否就绪，近期修改是否仍在处理中。
4. 清除不需要的分类、类型、颜色等筛选。
5. 用简短明确的语句查询，再逐步放宽描述。
6. 对颜色、比例等硬条件，同时使用相应筛选并打开结果确认。

AI 搜索基于已有可搜索信息，不是在每次查询时重新观看所有原图。存在漏检和误判时，可纠正描述，但不能保证任意表达都精确命中。

### 28.10 Quick 不见了 或收集后没入库

到“设置 → 导入与快捷窗口 → 快捷窗口”，点击“显示 / 找回快捷窗口”。检查折叠条是否只是收起。

收集后先查待确认状态与“最近收录”，确认是否已经点过导入、目标库是否正确、任务是否失败或等待。文件夹监控发现新文件不等于已经入库。

### 28.11 手机无法连接 或上传后电脑里没素材

确认手机与电脑处于能互通的同一局域网，软件设置已允许手机传图，而且本次服务确实已启动。使用当前二维码和配对信息，不沿用上一次截图。

检查电脑端是否仍在等待允许配对，再核对上传与入库两个阶段。上传完但待入库时，在底部任务中心展开“手机导入”，按提示继续处理。

网络不通时按系统提示检查连接或应用通信权限，不建议为了传图直接关闭全部防火墙。传输结束后停止服务。

### 28.12 恢复或复制后结果未确认

停止新的整理和重复恢复，保留原库、目标目录及错误提示。查看维护状态，使用界面提供的刷新、继续恢复或核验入口。

目标目录出现文件不代表复制已完成；数据库恢复成功不代表文件也已恢复。先恢复可判断的状态，再决定下一步。

### 28.13 如何提供有用的反馈

在“关于软件”确认版本和构建信息，按需从“备份与维护”导出诊断日志。日志保存在本机，导出本身不会自动发送。

反馈可以这样写：

- 使用版本：填写“关于软件”显示的版本。
- 操作步骤：从哪个页面开始，点了什么，选择了什么类型的文件。
- 期望结果：原本希望看到什么。
- 实际结果：完整错误文字或截图，是否每次发生。
- 文件情况：格式、大致大小、Copy 或 Link；必要时提供可公开的最小样本。

提交前检查日志、路径、截图与样本，去除账号密钥、私人内容和项目保密资料。优先使用能复现的普通样本，并通过软件或官网显示的反馈入口提交。

## 第29章 操作速查与术语

### 29.1 常用入口

- **导入资源**：网格等布局的素材区右下角＋；详细列表布局的顶部工具区＋。见第03章。
- **新建分类**：资产库侧栏“文件夹”标题旁＋。见第04章。
- **标签与评分**：选中素材后，右侧“整理信息”。见第05章。
- **组合筛选**：资产库顶部筛选区。见第06章。
- **项目**：左侧“项目”；先建项目，选素材后用底部“加入项目”。见第07章。
- **查看大图**：双击图片，或选中后点“查看所选图片”。见第09章。
- **模型大预览**：单击模型，在详情点击“大预览”。见第10章。
- **动作与姿态**：模型预览中的动画控制、“姿态/混合”。见第11章。
- **AI 配置**：设置中的“AI 分析与搜索”。见第13章。
- **AI 批量任务**：工具栏“AI 分析任务”，或选中后底部“AI 批量处理”。见第14章。
- **找回 Quick**：设置 → 导入与快捷窗口 → 快捷窗口。见第15章。
- **手机传图**：先在设置允许，再从“手机连接”启动并配对。见第16章。
- **目录同步**：设置 → 存储与资源库。见第17章。
- **备份与复制**：设置 → 备份与维护。见第18章。
- **任务状态**：主界面底部“任务”。见第19章。

### 29.2 鼠标与键盘

**主素材区**：单击选中；Ctrl 配合单击可增减选择；Shift 可进行范围选择；Ctrl+A 用于当前可选择的素材范围，操作前核对底部选中数量。不要在输入框内按全选后，假定已经选中素材。

**图片**：双击打开大图，左上角“返回”回到素材区。Esc 在全屏时先退出全屏，普通大图模式再返回。Space 的打开或关闭行为受当前焦点影响，文字输入或按钮焦点中不应当作通用快捷键。

**缩略图大小**：可以用界面尺寸按钮调整；支持的素材浏览位置也可使用 Ctrl 加鼠标滚轮。

**标签输入**：填写后点“添加”或按 Enter 提交。中文输入法先完成选字。

**模型动画**：预览中的播放暂停键默认 Space，可在“设置 → 预览”改为 K、P 或关闭。它有生效范围，不应与图片查看器或 Quick 的快捷键混用。

**Quick**：快捷收集、搜索和确认使用独立的界面与键盘提示，优先按当前窗口可见说明操作，见第15章。

### 29.3 这些词分别是什么意思

**资产或素材**：JAMY 管理的一项内容及其记录，不一定是库内复制文件。

**托管文件**：由资源库保存的文件副本。删除这份文件与仅移除记录不同。

**索引或引用**：记录文件的位置与相关信息。Link 通常依赖库外原文件。

**缩略图**：用于列表浏览的小图，不能代替原图或模型。

**色板**：从图片提取的代表颜色及比例。颜色筛选依据已准备的色板匹配。

**材质槽**：模型中不同材质对应的设置位置。调整某个槽与全局调整范围不同。

**HDRI**：用于模型预览环境的高动态范围图像；JAMY 相应入口接受 HDR、EXR，仍受读取与处理条件限制。

**姿态**：某个时刻的骨骼状态。JAMY 保存的姿态与对应模型兼容，不是任意角色都能套用的动作文件。

**项目用途**：素材在某个项目中的角色，例如参考、提示词、图片、视频或声音。它不改变原文件格式。

**AI 图片分析**：把支持的静态图片交给已配置模型，生成描述和标签。

**准备 AI 搜索**：将已有描述、标签等信息整理成可做语义查找的数据。它与看图分析是不同任务。

**API**：软件调用外部服务的接口。服务地址、密钥和模型都需要有效配置，可能产生第三方费用。

**记录备份**：保存可恢复的整理数据，不包含全部素材原文件、外部贴图和所有环境配置。

**目录同步**：检查登记目录的文件变化并更新相应管理状态，不等于网盘同步或文件历史备份。

### 29.4 使用范围提醒

网页能下载的素材不一定允许转载或商用；是否可用，应根据素材来源和许可判断。

本册没有把 Blender 联动插件、全部 DCC 工程原生预览、任意骨架重定向、全资产 AI 理解、多用户协作或无限画布列为当前可操作功能。使用时以当前版本实际提供的入口为准。

素材的重要程度越高，越应同时保留原文件与整理记录备份。软件帮助你管理资料，不能代替对最终交付内容、文件完整性和使用权限的检查。
