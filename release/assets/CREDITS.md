# 截图与展示素材说明

README 当前使用 Windows JAMY **3.1.13** 的已有亮色界面实拍，不是生成的界面效果图，也未替换截图中的界面内容。

- `jamy-studio-library.png`：3.1.13 r2 实际包中的资产库与模型详情，包含真实 GLB 文件及 PNG 图片。
- `jamy-studio-model.png`：同版模型材质验证界面，展示 GLB 双材质模型及实际贴图、材质槽设置。
- `jamy-studio-ai.png`：同版 AI 批量任务的数量确认界面；截图表示任务确认流程，不表示已经完成图片推理或证明识别质量。

2026-10-30 构建增加免费测试欢迎页与离线手册，上述模型和 AI 业务视图沿用同版已有实拍，不以旧截图表示新欢迎页或手册界面。展示素材为独立功能验证样例，不是用户真实项目；GLB 模型不是 PNG 模型效果图，材质贴图与图片素材则确实为 PNG。

当前截图没有展示全部支持格式。HDR、EXR、FBX、音视频等的支持范围和限制，以 README 格式表、`release/LIMITS.md` 与手册为准，不能根据截图推断所有编码均可预览。

品牌标识来自 JAMY 软件现有资源。旧的中英文封面与历史截图保留在仓库历史中，不作为当前版本界面展示依据。
